## 🎥 완성본 먼저 보기 (5분)

### "여러분, 이거 어떻게 만든 것 같아요?"

> 강사가 미리 만든 **"시험 기간 학생 고양이의 하루"** 쇼츠 영상을 재생합니다.

**강사 시연 영상 대본 (미리 제작 필요):**

```
[장면 1] 월요일 아침... 오늘 시험인데 😱   (6초)
[장면 2] 도서관 자리는 이미 만석... 🐱     (7초)
[장면 3] 급식 먹고 다시 공부... 냥 📚      (7초)
[장면 4] 시험 끝! 일단 잠부터 😴           (7초)
[장면 5] 내일 또 시험... 고양이 인생이란 🎒  (8초)

총 35초 / BGM: 귀엽고 아기자기한 피아노 멜로디
```

영상 재생 후, 수강생에게 질문합니다:

> "이 영상 만드는 데 얼마나 걸렸을 것 같아요?"

잠깐 답변을 받은 뒤 공개합니다:

> 대본 3분, 이미지 5분, Vrew 조립 25분. 총 **33분** 걸렸습니다.
> 오늘 90분 안에 여러분도 이 영상을 직접 만들어 가져갑니다. 🎬

## ✍️ 재료 준비 1: ChatGPT로 대본 만들기 (15분)

### AI는 당신의 대본 작가다

영상 대본을 처음부터 쓰면 막막하다.  
==ChatGPT에게 상황을 설명하면 30초 안에 초안이 나온다.==

| 준비물 | 확인 |
|--------|------|
| ChatGPT 접속 (chat.openai.com) | □ |
| 모델: GPT-4o 선택 | □ |

### ChatGPT 대본 프롬프트 (완성형)

아래 프롬프트를 그대로 복사해서 ChatGPT에 붙여넣으세요.

```prompt
너는 SNS 숏폼 콘텐츠 전문 크리에이터야.

귀여운 고양이가 학생인 척 학교 생활하는 재미있는 쇼츠 대본을 써줘.

조건:
- 영상 길이: 30~40초 (장면당 자막 20자 이내)
- 말투: 공감되고 귀여운 톤, 학생/직장인 둘 다 웃길 수 있게
- 구성: 장면 5개, 각 장면 자막 1줄
- 주제: 시험 기간 고양이의 하루
- 각 장면에 이모지 1개 포함

출력 형식:
[장면 1] 자막 문구
[장면 2] 자막 문구
[장면 3] 자막 문구
[장면 4] 자막 문구
[장면 5] 자막 문구
```

> 장면 번호를 붙이는 이유: 나중에 Vrew에서 장면 순서대로 이미지를 배치하기 때문입니다.

### 결과가 마음에 안 들면? 이렇게 수정하세요

**수정 프롬프트 A** — 특정 장면을 바꾸고 싶을 때
```prompt
3번 장면을 더 공감되게, 20자 이내로 바꿔줘.
```

**수정 프롬프트 B** — 전체 톤을 바꾸고 싶을 때
```prompt
전체 톤을 더 MZ 감성으로 바꾸고 이모지를 더 재밌는 걸로 교체해줘.
```

> ==완벽한 대본을 만들 필요 없어요.== Gemini 버전과 비교해서 고를 거니까, 일단 첫 버전을 복사해두세요.

## 🔵 재료 준비 2: Gemini로 버전 비교하기 (10분)

### 같은 주제, 다른 느낌

ChatGPT가 쓴 대본과 Gemini가 쓴 대본은 미묘하게 다르다.  
==두 버전을 보고 마음에 드는 문구를 골라 섞으면 내 대본이 된다.==

| | ChatGPT | Gemini |
|--|---------|--------|
| 강점 | 구조적, 지시사항 정확 반영 | 감성적, 맥락 풍부 |
| 접속 | chat.openai.com | gemini.google.com |

### Gemini 대본 프롬프트 (완성형)

```prompt
인스타그램/유튜브 쇼츠용 AI 동물 콘텐츠 대본을 써줘.

설정: 고양이가 중학생인데 시험 기간임
장면 수: 5개
각 자막: 20자 이내
분위기: 귀엽고 공감되는, 살짝 지쳐있는 고양이

장면 번호와 자막만 깔끔하게 출력하고,
마지막에 BGM 분위기 추천을 한 줄만 덧붙여줘.
```

### 두 버전 비교하는 법

| 확인 포인트 | 기준 |
|------------|------|
| 문구 길이 | 한 줄 20자 이내인가? (Vrew 자막 권장) |
| 공감도 | 소리 내어 읽었을 때 웃기거나 공감되는가? |
| 리듬 | 장면마다 비슷한 호흡으로 읽히는가? |

두 버전을 비교해서 **마음에 드는 문구 5개**를 메모장에 저장하세요.

> ==지금 완벽한 대본을 만들 필요 없어요.== Vrew에서 언제든 자막을 수정할 수 있습니다.

## 🖼️ 재료 준비 3: AI로 이미지 5장 만들기 (5분)

### 사진 없어도 괜찮아요 — AI가 그려줍니다

실제 고양이 사진이 없어도 된다.  
==DALL-E와 Gemini ImageFX로 Pixar 스타일 고양이 이미지를 5장 만든다.==

### ChatGPT DALL-E 이미지 프롬프트 (장면별 완성형)

ChatGPT 대화창에서 **이미지 아이콘(카메라 버튼)**을 누르고 아래 프롬프트를 입력하세요.

| 장면 | 프롬프트 |
|------|----------|
| 장면 1 (시험 당일 아침) | `A cute cartoon cat wearing school uniform, lying in bed with alarm clock ringing, stressed expression, bedroom background, morning light, vertical 9:16, Pixar style` |
| 장면 2 (도서관 만석) | `A cute cat student with backpack, standing in library looking for empty seat, all seats taken, disappointed face, vertical 9:16, soft illustration style` |
| 장면 3 (급식) | `A cute cat student eating school lunch alone, holding chopsticks, cafeteria background, tired but cute expression, vertical 9:16, warm tone` |
| 장면 4 (시험 후 낮잠) | `A cute cat student sleeping on school desk after exam, peaceful expression, pencils and eraser around, golden afternoon light, vertical 9:16, cozy illustration` |
| 장면 5 (집에서 쉬기) | `A cute cat student slumping on sofa at home, school bag dropped on floor, TV remote in hand, relieved expression, cozy home background, vertical 9:16` |

> ==Tip: 모든 프롬프트에 `vertical 9:16`을 넣어야 릴스/쇼츠 비율로 생성됩니다.==

### Gemini ImageFX 프롬프트 (한글 가능)

접속: **labs.google/fx/tools/image-fx**

```prompt
학생 교복 입은 귀여운 고양이, 시험 기간, 지친 표정,
파스텔 색감, 세로 비율, 픽사 애니메이션 스타일, 귀엽고 공감되는 분위기
```

| 비교 | DALL-E | Gemini ImageFX |
|------|--------|----------------|
| 강점 | 영어 프롬프트 정확 반영, 구도 안정적 | 한글 프롬프트 가능, 감성적 결과 |
| 추천 상황 | 구체적 장면 묘사 | 전체 분위기 이미지 |

### 이미지 저장하기

1. 생성된 이미지 오른쪽 클릭 → **"다른 이름으로 저장"**
2. 바탕화면에 `고양이쇼츠` 폴더 만들고 저장
3. 파일명: `scene01.png` `scene02.png` ... `scene05.png`

> 파일명을 미리 정리하면 Vrew에서 불러올 때 헷갈리지 않아요!

## 🎬 Vrew로 영상 조립하기 (25분)

### Vrew(브루)가 뭔가요?

==Vrew==는 텍스트와 이미지만 있으면 자동으로 영상을 만들어주는 무료 편집 프로그램이다.  
자막도 자동, 화면 전환도 자동. 우리는 재료만 넣으면 된다.

| 항목 | 내용 |
|------|------|
| 다운로드 | vrew.ai |
| 운영체제 | Windows / Mac / 모바일 |
| 가격 | **무료** (워터마크 없이 내보내기 가능) |

---

### Step 1: 새 프로젝트 시작 (3분)

1. Vrew 실행 → 상단 **"새로 만들기"** 클릭
2. **"이미지로 비디오 만들기"** 선택
3. 화면 비율: ==**9:16 (세로형)**== 선택 → 확인

> "16:9 아닌가요?" 라고 물으면: 릴스·틱톡·쇼츠는 모두 세로예요. 9:16이 맞습니다!

---

### Step 2: 이미지 5장 불러오기 (3분)

1. 화면 왼쪽 **"클립 추가"** 버튼 클릭
2. 바탕화면 `고양이쇼츠` 폴더에서 `scene01.png` ~ `scene05.png` 선택
3. ==**Ctrl 키를 누른 채로 5장 동시 선택**== → 열기
4. 장면 순서 확인 (드래그로 조정 가능)

| 체크 포인트 | |
|------------|--|
| 이미지 5장 모두 불러왔는가? | □ |
| 순서가 장면 1~5 순서인가? | □ |
| 9:16 세로 비율로 잘 들어왔는가? | □ |

---

### Step 3: 각 장면에 자막 입력 (10분)

1. 타임라인에서 **첫 번째 클립** 클릭
2. 오른쪽 패널 **"자막"** 탭 클릭
3. ChatGPT/Gemini에서 고른 **[장면 1]** 문구 입력

장면별로 반복 (총 5회):

| 장면 | 권장 표시 시간 |
|------|-------------|
| 장면 1 | 6~7초 |
| 장면 2 | 6~7초 |
| 장면 3 | 6~7초 |
| 장면 4 | 6~7초 |
| 장면 5 | 7~8초 |

> ==자막 폰트 추천: 나눔스퀘어 Bold 또는 Pretendard==  
> 자막 색: **흰색 + 검정 테두리** (어떤 배경에서도 잘 보임)

---

### Step 4: 배경음악 추가 (5분)

**방법 A: Vrew 내장 무료 음원 (초보자 권장)**

1. 상단 메뉴 **"삽입"** → **"배경음악"**
2. 장르: **Acoustic / Pop / Bright** 카테고리
3. 미리 듣기 후 마음에 드는 트랙 선택 → **삽입**
4. 볼륨: **20~30%** (자막보다 작아야 함)

**방법 B: Suno AI로 음악 직접 만들기 (선택사항)**

접속: **suno.com**

```prompt
cute and playful piano melody for cat student short video,
upbeat but slightly tired feeling, no lyrics, 30-40 seconds
```

| 음악 체크리스트 | |
|---------------|--|
| 볼륨이 자막보다 작은가? | □ |
| 영상 끝에서 자연스럽게 끝나는가? | □ |
| 저작권 문제 없는 음원인가? | □ |

---

### Step 5: 화면 전환 효과 (2분)

1. 클립과 클립 사이 **"+"** 버튼 클릭
2. **"전환 효과"** → **Fade** 또는 **Dissolve** 선택
3. 전환 시간: **0.5초**

> 화려한 효과는 오히려 집중을 방해해요. ==단순한 Fade가 가장 세련됩니다.==

---

### Step 6: 최종 미리보기 (2분)

상단 **재생(▶)** 버튼을 눌러 처음부터 끝까지 한 번 확인하세요.

| 최종 점검 | |
|---------|--|
| 자막에 오타가 없는가? | □ |
| 이미지와 자막 내용이 맞는가? | □ |
| 음악이 자연스럽게 깔리는가? | □ |
| 전체 길이가 30~45초인가? | □ |

## 📤 완성하고 공유하기 (20분)

### 영상 내보내기

1. 상단 메뉴 **"내보내기"** 클릭
2. 형식: **MP4**
3. 해상도: ==**1080 × 1920**== (Full HD 세로)
4. 저장 위치: 바탕화면 `고양이쇼츠` 폴더
5. **내보내기 시작** → 완료 대기 (1~2분)

> 내보내기가 진행되는 동안 다음 단계를 미리 읽어두세요!

---

### 인스타그램 릴스 업로드 (선택)

| 단계 | 방법 |
|------|------|
| 1 | 인스타그램 앱 → **+** 버튼 |
| 2 | **릴스** 탭 선택 |
| 3 | 갤러리에서 방금 내보낸 MP4 선택 |
| 4 | 커버 이미지 설정 (첫 프레임 권장) |
| 5 | 캡션 작성 후 **공유** |

**캡션도 AI로 쓰세요:**

```prompt
방금 만든 "시험 기간 고양이 쇼츠" 영상에 달 인스타그램 캡션을 써줘.
해시태그 10개 포함, 이모지 사용, 친근한 말투.
```

---

### 미니 발표 (10분)

> 이 시간이 오늘의 하이라이트입니다. 🎉

완성한 영상을 재생하고, 한 마디만 해주세요.

| 발표 포인트 | 예시 |
|------------|------|
| 가장 마음에 드는 장면 | "4번 낮잠 자는 고양이 이미지가 너무 귀여워요" |
| 아쉬운 점 | "자막 폰트를 바꾸고 싶어요" |
| 다음에 만들고 싶은 것 | "강아지 버전도 만들어보고 싶어요" |

> ==완성 못 했어도 괜찮아요.== 오늘 배운 흐름이 중요합니다. 집에서 30분이면 완성할 수 있어요.
