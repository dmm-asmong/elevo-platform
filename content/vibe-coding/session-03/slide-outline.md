슬라이드 4 이론 — 연쇄적 사고(CoT) 프롬프팅 (이론 페이지)
* 소요시간: 이론 15분 중 전반부
* 연쇄적 사고(Chain-of-Thought, CoT) 프롬프팅이란?
* 복잡한 문제를 작은 단계로 쪼개서 AI에게 하나씩 순서대로 시키는 기법
* 비유: 레시피 없이 "삼겹살 구워줘"라고만 하면 되긴 하지만, "1단계: 고기를 실온에 꺼내둬 → 2단계: 팬을 달궈줘 → 3단계: 중불에서 앞뒤로 구워줘 → 4단계: 소금을 뿌려줘"라고 하면 훨씬 정확하게 해줌
* 왜 필요한가?
* AI에게 한 번에 긴 요청을 하면 중간에 빠뜨리거나 엉뚱한 방향으로 갈 수 있음
* 단계별로 나누면 각 단계를 확인하며 진행할 수 있어서 실수를 줄일 수 있음
* 대화를 이어가며 점진적으로 발전시키는 것이 바이브 코딩의 핵심 방식
* 쉬운 풀이 박스:
* CoT(Chain-of-Thought) = 생각의 연쇄. AI에게 "단계별로 생각하며 처리해줘"라고 하는 기법
* 인터랙티브(Interactive) = 사용자가 클릭하거나 입력하면 반응하는 것. 버튼을 누르면 뭔가 일어나는 것
* JavaScript(자바스크립트) = 웹페이지에 동작(기능)을 추가하는 프로그래밍 언어. HTML이 뼈대, CSS가 옷이라면, JavaScript는 뇌에 해당
슬라이드 5 이론 — 단계별 프롬프팅 실전 예시 (이론 페이지)
* 한 번에 모든 걸 시키는 방식 (비추천):
* "운세 뽑기 웹앱을 만들어줘. 20개 운세가 있고 버튼 누르면 랜덤으로 나오고 애니메이션도 넣고 배경도 예쁘게 해줘"
* 결과: 뭔가 나오긴 하지만 내가 원하는 것과 다를 가능성이 높음
* 단계별로 쪼개서 시키는 방식 (추천):
* 1단계: "재미있는 운세 문장 20개를 만들어줘"
* 2단계: "이 운세 목록을 사용해서, 버튼을 누르면 랜덤으로 하나가 화면에 표시되는 HTML/JavaScript 코드를 만들어줘"
* 3단계: "배경을 보라색 그라데이션으로, 운세가 나올 때 페이드인 애니메이션을 넣어줘"
* 4단계: "뽑은 횟수를 카운트해서 화면에 보여줘"
* 각 단계마다 결과를 확인하고 → 다음 단계로 진행
* 핵심: 작게 시작하고, 확인하고, 점점 키우기!
슬라이드 6 이론 — 코드 실행 방법 복습 (이론 페이지)
* AI가 생성한 코드를 실행하는 방법 복습:
* 방법 1: Google AI Studio 내 미리보기 기능 (있다면 가장 편리)
* 방법 2: 코드 전체 복사 → 메모장에 붙여넣기 → .html로 저장 → 크롬으로 열기
* 방법 3: 온라인 코드 실행기 (codepen.io 등)에 붙여넣기
* 오늘의 팁: AI에게 "HTML, CSS, JavaScript를 하나의 파일에 합쳐서 만들어줘"라고 요청하면 하나의 .html 파일만 저장하면 됨

슬라이드 9 실습 1 — Step 1: 운세 데이터 만들기 (실습 페이지)
* 프롬프트 예시:
고등학생 친구들이 재미있어할 오늘의 운세 문장 20개를 만들어줘.
유머러스하고 긍정적인 느낌으로, 학교생활과 관련된 내용을 섞어줘.
예시: "오늘 점심 급식이 당신의 인생 급식이 될 예정!"
이런 톤으로 20개 만들어줘.
* 결과를 확인하고, 마음에 안 드는 운세가 있으면 "3번이랑 7번 운세를 더 재미있게 바꿔줘"처럼 수정 요청
* 강사 유의사항: 이 단계에서 학생들이 직접 운세 문장을 추가하거나 수정하게 해도 좋다. "AI가 만든 거에 내 아이디어를 섞어보세요!"
슬라이드 10 실습 1 — Step 2: 기본 기능 구현 (실습 페이지)
* 프롬프트 예시:
방금 만든 운세 20개를 사용해서 "오늘의 운세 뽑기" 웹앱을 만들어줘.
기능:
* 화면 가운데에 큰 "운세 뽑기" 버튼이 있다
* 버튼을 클릭하면 20개 중 랜덤으로 하나가 화면에 표시된다
* HTML, CSS, JavaScript를 하나의 파일에 합쳐서 작성해줘
디자인:
* 배경은 진한 보라색에서 남색으로 가는 그라데이션
* 버튼은 둥글고 크게, 누르고 싶은 느낌으로
* 운세 문장은 하얀 큰 글씨로 표시
* AI의 결과를 복사 → .html 파일로 저장 → 브라우저에서 열기
* 버튼을 눌러서 실제로 동작하는지 확인!
* 강사 멘트: "와, 버튼 누르면 진짜 운세가 바뀌죠? 여러분이 코딩을 한 줄도 안 했는데, AI가 만들어준 코드가 실제로 돌아가는 거예요!"
슬라이드 11 실습 1 — Step 3: 디자인 업그레이드 (실습 페이지)
* 프롬프트 예시:
지금 만든 운세 뽑기 앱을 더 예쁘게 업그레이드해줘.
* 운세가 나타날 때 페이드인 애니메이션을 넣어줘
* 버튼을 누를 때 버튼이 살짝 눌리는 효과를 추가해줘
* 페이지 상단에 "오늘의 운세 🔮" 제목을 크게 넣어줘
* 운세 뽑기 횟수를 카운트해서 화면 하단에 "지금까지 N번 뽑았습니다"를 보여줘
* 결과를 실행해서 확인. 애니메이션이 잘 되는지, 횟수가 올라가는지 테스트
* 강사 유의사항: 이 단계에서 에러가 나는 학생이 있을 수 있음. "에러가 나면 당황하지 마세요. 에러 메시지를 그대로 복사해서 AI에게 '이 에러를 고쳐줘'라고 하면 됩니다." 다음 회차에서 본격적으로 배울 내용이지만 미리 경험하게 한다.

* "다시 뽑기" 버튼 추가하기
* 운세 카테고리(학업운/연애운/금전운) 선택 기능 추가하기
* 강사 유의사항: 학생마다 속도 차이가 크다. 빠른 학생에게는 "카테고리 선택 기능"처럼 복잡한 도전 과제를 추가 제시. 느린 학생에게는 기본 디자인 수정만으로도 충분하다고 격려.
