## 🧠 연쇄적 사고(CoT) 프롬프팅이란?

==연쇄적 사고(Chain-of-Thought, CoT) 프롬프팅==이란 복잡한 문제를 작은 단계로 쪼개서 AI에게 하나씩 순서대로 시키는 기법이다.

### 삼겹살 비유로 이해하기

> 레시피 없이 "삼겹살 구워줘"라고만 해도 되긴 하지만, 단계별로 지시하면 훨씬 정확하다.

| 방식 | 예시 |
|------|------|
| 한 번에 통째로 | "삼겹살 구워줘" |
| 단계별로 쪼개서 | 1단계: 고기를 실온에 꺼내둬 → 2단계: 팬을 달궈줘 → 3단계: 중불에서 앞뒤로 구워줘 → 4단계: 소금을 뿌려줘 |

### 왜 단계별 프롬프팅이 필요한가?

- AI에게 한 번에 긴 요청을 하면 중간에 빠뜨리거나 엉뚱한 방향으로 갈 수 있다
- 단계별로 나누면 각 단계를 확인하며 진행할 수 있어서 실수를 줄일 수 있다
- ==대화를 이어가며 점진적으로 발전시키는 것==이 바이브 코딩의 핵심 방식이다

---

## 📖 용어 정리

| 용어 | 쉬운 풀이 |
|------|-----------|
| ==CoT (Chain-of-Thought)== | 생각의 연쇄. AI에게 "단계별로 생각하며 처리해줘"라고 하는 기법 |
| ==인터랙티브 (Interactive)== | 사용자가 클릭하거나 입력하면 반응하는 것. 버튼을 누르면 뭔가 일어나는 것 |
| ==JavaScript (자바스크립트)== | 웹페이지에 동작(기능)을 추가하는 프로그래밍 언어. HTML이 뼈대, CSS가 옷이라면, JavaScript는 뇌에 해당 |

## ⚖️ 프롬프팅 방식 비교

### 한 번에 모든 걸 시키는 방식 (비추천)

```prompt
운세 뽑기 웹앱을 만들어줘. 20개 운세가 있고 버튼 누르면 랜덤으로 나오고 애니메이션도 넣고 배경도 예쁘게 해줘
```

결과: 뭔가 나오긴 하지만 내가 원하는 것과 다를 가능성이 높다.

### 단계별로 쪼개서 시키는 방식 (추천)

| 단계 | 내용 |
|------|------|
| 1단계 | 재미있는 운세 문장 20개를 만들어줘 |
| 2단계 | 이 운세 목록을 사용해서 버튼 클릭 시 랜덤 운세가 표시되는 HTML/JavaScript 코드를 만들어줘 |
| 3단계 | 배경을 보라색 그라데이션으로, 운세가 나올 때 페이드인 애니메이션을 넣어줘 |
| 4단계 | 뽑은 횟수를 카운트해서 화면에 보여줘 |

> **핵심:** ==작게 시작하고, 확인하고, 점점 키우기!== 각 단계마다 결과를 확인한 뒤 다음 단계로 진행한다.

## 💾 AI가 만든 코드 실행하는 방법

| 방법 | 설명 |
|------|------|
| 방법 1 | Google AI Studio 내 미리보기 기능 (있다면 가장 편리) |

## 🛠️ 실습 — 오늘의 운세 뽑기 만들기

### Step 1: 운세 데이터 만들기

```prompt
고등학생 친구들이 재미있어할 오늘의 운세 문장 20개를 만들어줘.
유머러스하고 긍정적인 느낌으로, 학교생활과 관련된 내용을 섞어줘.
예시: "오늘 점심 급식이 당신의 인생 급식이 될 예정!"
이런 톤으로 20개 만들어줘.
```

결과를 확인하고, 마음에 안 드는 운세가 있으면 아래처럼 수정 요청할 수 있다.

```prompt
3번이랑 7번 운세를 더 재미있게 바꿔줘
```

AI가 만든 운세에 내 아이디어를 직접 섞어서 수정해도 좋다.

---

### Step 2: 기본 기능 구현

```prompt
방금 만든 운세 20개를 사용해서 "오늘의 운세 뽑기" 웹앱을 만들어줘.
기능:
* 화면 가운데에 큰 "운세 뽑기" 버튼이 있다
* 버튼을 클릭하면 20개 중 랜덤으로 하나가 화면에 표시된다
* HTML, CSS, JavaScript를 하나의 파일에 합쳐서 작성해줘
디자인:
* 배경은 진한 보라색에서 남색으로 가는 그라데이션
* 버튼은 둥글고 크게, 누르고 싶은 느낌으로
* 운세 문장은 하얀 큰 글씨로 표시
```

1. AI의 결과를 복사한다
2. `.html` 파일로 저장한다
3. 브라우저에서 열어 버튼을 눌러 실제로 동작하는지 확인한다

---

### Step 3: 디자인 업그레이드

```prompt
지금 만든 운세 뽑기 앱을 더 예쁘게 업그레이드해줘.
* 운세가 나타날 때 페이드인 애니메이션을 넣어줘
* 버튼을 누를 때 버튼이 살짝 눌리는 효과를 추가해줘
* 페이지 상단에 "오늘의 운세 🔮" 제목을 크게 넣어줘
* 운세 뽑기 횟수를 카운트해서 화면 하단에 "지금까지 N번 뽑았습니다"를 보여줘
```

결과를 실행해서 확인한다. 애니메이션이 잘 되는지, 횟수가 올라가는지 테스트해본다.

> **에러가 났을 때:** 당황하지 말고, 에러 메시지를 그대로 복사해서 AI에게 !!`"이 에러를 고쳐줘"`!!라고 하면 된다.

## ✅ 오늘의 핵심 정리

1. ==CoT(연쇄적 사고) 프롬프팅==은 복잡한 요청을 작은 단계로 쪼개서 AI에게 순서대로 시키는 기법이다
2. 단계별로 나누면 각 단계를 확인하고 수정할 수 있어서 원하는 결과에 더 가깝게 만들 수 있다
3. ==인터랙티브 웹앱==은 JavaScript가 있어야 가능하다. HTML(뼈대) + CSS(디자인) + JavaScript(동작)가 합쳐진 구조다
4. AI가 만든 코드에 에러가 나도 괜찮다. 에러 메시지를 그대로 AI에게 보내면 고쳐준다
5. 바이브 코딩의 핵심은 ==작게 시작하고, 확인하고, 점점 키우기==다
