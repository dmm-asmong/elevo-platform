> **오늘의 핵심 메시지:** ==AI는 도구, 내가 감독!==

---

## 🤖 바이브 코딩이란?

### "말로 코딩하는 시대"가 왔다

==바이브 코딩(Vibe Coding)==은 2025년 초, 전 OpenAI 공동창업자 **안드레이 카르파시(Andrej Karpathy)**가 처음 사용한 용어다.

복잡한 프로그래밍 문법을 외우는 대신, 평소 쓰는 **자연어**로 AI에게 "이런 거 만들어줘"라고 설명하면 ==AI가 코드를 대신 작성==해주는 방식이다.

> 카페에서 주문하듯 "이런 앱 만들어줘"라고 말하면 AI 바리스타가 만들어주는 것.

### AI를 이해하는 핵심 비유

AI는 **"지식은 엄청 많지만 판단력은 부족한 똑똑한 인턴"**이다.

- 인턴에게 일을 시킬 때 ==뭐라고 말하느냐==에 따라 결과가 달라진다
- 무엇을 만들지 결정하고, 결과를 확인하는 건 **사람(나)의 몫**이다

### 📖 용어 정리

| 용어 | 쉬운 풀이 |
|------|-----------|
| **자연어** | 우리가 일상에서 쓰는 한국어·영어 등의 말. 프로그래밍 언어가 아닌 사람의 언어 |
| **LLM** (대규모 언어 모델) | 엄청나게 많은 글을 읽고 학습해서 사람처럼 글을 쓸 수 있게 된 AI. Gemini, ChatGPT 등이 여기에 해당 |
| **프롬프트** | AI에게 보내는 질문이나 명령. "이것 좀 만들어줘"라고 쓰는 그 문장 자체 |

## ⚡ 왜 바이브 코딩을 배울까?

### 기존 코딩 vs 바이브 코딩

| | 기존 코딩 | 바이브 코딩 |
|---|-----------|------------|
| **시작** | 프로그래밍 언어 문법 공부 필수 | 아이디어만 있으면 시작 가능 |
| **작성** | 한 글자라도 틀리면 에러 | 말로 설명하면 AI가 코드 작성 |
| **수정** | 직접 원인 찾아 고쳐야 함 | "이렇게 바꿔줘"라고 요청하면 됨 |
| **결과** | 첫 결과물까지 진입장벽 높음 | 아이디어 → 결과물이 바로 나옴 |

### 바이브 코딩에서 가장 중요한 것

코드가 아니라 ==기획력==이다.

1. 내가 **뭘 만들고 싶은지** 명확히 아는 것
2. AI에게 **어떻게 설명할지** 정리하는 것
3. AI가 만든 결과물이 **맞는지 확인**하는 것

## 💬 Gemini 소개

**Gemini**는 구글(Google)이 만든 AI 대화 모델이다.

- 텍스트, 이미지, 코드 등을 이해하고 생성할 수 있다
- !!한국어로 말해도 알아듣고, 코드도 만들어준다!!

### Gemini 모델 종류

| 모델 | 특징 | 언제 쓸까 |
|------|------|-----------|
| **Gemini Flash** | 빠르고 가벼움 | 수업 실습 — 간단한 작업 |
| **Gemini Pro** | 더 정교하고 강력함 | 복잡한 작업·긴 문서 처리 |

### 📖 용어 정리

| 용어 | 쉬운 풀이 |
|------|-----------|
| **모델** | AI의 두뇌에 해당하는 프로그램. 종류마다 성능과 속도가 다름 |
| **토큰** | AI가 글을 이해하는 단위. 한국어 한 글자 ≈ 1~2토큰 |

## 🛠 Google AI Studio

==Google AI Studio==는 구글이 무료로 제공하는 AI 실험실(웹사이트)이다.

- 브라우저에서 바로 Gemini에게 말을 걸고 코드를 만들어달라고 할 수 있는 공간
- 별도 설치 없이 **구글 계정만 있으면** 바로 사용 가능

### 화면 구성

| 영역 | 설명 |
|------|------|
| 왼쪽 — **프롬프트 입력** | AI에게 할 말을 적는 곳 |
| 오른쪽 — **결과 출력** | AI가 생성한 답변이 나타나는 곳 |
| 상단 — **모델 선택** | 어떤 AI 모델을 사용할지 고르는 곳 |
| **시스템 인스트럭션** | AI에게 "너는 OO 역할이야"라고 미리 설정하는 곳 |

### 📖 용어 정리

| 용어 | 쉬운 풀이 |
|------|-----------|
| **시스템 인스트럭션** | AI에게 미리 부여하는 역할이나 규칙. "너는 친절한 웹 개발자야"처럼 AI의 성격을 설정하는 것 |

## 🚀 실습 — Google AI Studio 접속하기

### 접속 단계

1. **크롬 브라우저** 주소창에 입력: `aistudio.google.com`
2. **구글 계정**으로 로그인 (학교 계정 또는 개인 계정 모두 가능)
3. 왼쪽 메뉴에서 **"새 채팅(New Chat)"** 또는 **"프롬프트 만들기"** 클릭
4. 모델 선택에서 **"Gemini Flash"** 선택
5. 프롬프트 입력창에 아무 말이나 입력하고 전송!

### 처음 입력해볼 프롬프트 예시

```prompt
안녕! 너는 누구야?
```

```prompt
오늘 기분 좋아지는 농담 하나 해줘
```

```prompt
고등학생인 나에게 오늘 할 수 있는 재미있는 일 3가지 추천해줘
```

## 🎯 오늘의 결과물 — 자기소개 카드

### 목표

Gemini에게 프롬프트를 입력해서 ==HTML 자기소개 카드 코드==를 받고, 브라우저에서 직접 실행해보기.

### 📖 용어 정리

| 용어 | 쉬운 풀이 |
|------|-----------|
| **HTML** | 웹페이지를 만드는 언어. 브라우저가 읽을 수 있는 설계도 |
| **CSS** | 웹페이지를 예쁘게 꾸미는 언어. 색상·글꼴·배치 등을 담당 |

### 프롬프트 작성 가이드

**"내 정보 + 디자인 요청"**을 함께 넣어서 입력한다. 구체적으로 쓸수록 결과가 좋아진다!

```prompt
나를 소개하는 예쁜 HTML 자기소개 카드 웹페이지를 만들어줘.

내 정보:
- 이름: 홍길동
- 학교: OO고등학교 1학년
- 취미: 농구, 음악 듣기
- 좋아하는 색: 파란색
- 한마디: "오늘도 화이팅!"

디자인 요청:
- 배경은 파란 계열 그라데이션
- 카드 형태로 가운데 정렬
- 이모지를 적절히 넣어줘
- 모서리는 둥글게
- HTML, CSS를 한 파일에 작성해줘
```

### 코드 실행하는 방법

**방법 A — AI Studio 내에서 바로 확인**

- AI Studio에 미리보기 기능이 있다면 바로 실행

**방법 B — 파일로 저장해서 실행**

1. AI가 만들어준 코드 전체 복사 (`Ctrl+A` → `Ctrl+C`)
2. 메모장(Notepad) 열고 붙여넣기 (`Ctrl+V`)
3. "다른 이름으로 저장" → 파일 이름: `mycard.html`, 파일 형식: ==모든 파일==
4. 저장한 파일을 크롬 브라우저 창에 끌어다 놓기
5. 🎉 내 자기소개 카드가 화면에 나타남!

## ✅ 오늘의 핵심 정리

1. **바이브 코딩** = 말로 AI에게 설명해서 코드를 만드는 방식. 문법 몰라도 된다.
2. **프롬프트** = AI에게 보내는 말. ==구체적으로 쓸수록 결과가 좋아진다.==
3. **수정이 실력** = 처음 결과가 별로여도 괜찮다. 수정 요청하며 발전시키는 게 진짜 실력이다.
4. **AI는 도구, 내가 감독** = 무엇을 만들지 결정하고 결과를 확인하는 건 항상 나의 몫이다.
