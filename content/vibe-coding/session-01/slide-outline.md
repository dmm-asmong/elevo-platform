슬라이드 4 도입 — 바이브 코딩이란? (이론 페이지)
* 제목: "말로 코딩하는 시대"가 왔습니다
* 바이브 코딩(Vibe Coding)이란?
* 2025년 초, 전 OpenAI 공동창업자 안드레이 카르파시(Andrej Karpathy)가 처음 사용한 용어
* 복잡한 프로그래밍 문법을 외우는 대신, 우리가 평소에 쓰는 말(자연어)로 AI에게 "이런 거 만들어줘"라고 설명하면 AI가 코드를 대신 작성해주는 방식
* 쉽게 말하면: 카페에서 주문하듯이 "이런 앱 만들어줘"라고 말하면 AI 바리스타가 만들어주는 것
* 핵심 비유: AI는 "지식은 엄청 많지만 판단력은 부족한 똑똑한 인턴"
* 인턴에게 일을 시킬 때 뭐라고 말하느냐에 따라 결과가 달라진다
* 결국 무엇을 만들지 결정하고, 결과를 확인하는 건 사람(여러분)의 몫
* 쉬운 풀이 박스:
* 자연어(Natural Language) = 우리가 일상에서 쓰는 한국어, 영어 등의 말. 프로그래밍 언어가 아닌 사람의 언어
* LLM(Large Language Model, 대규모 언어 모델) = 엄청나게 많은 글을 읽고 학습해서 사람처럼 글을 쓸 수 있게 된 AI. Gemini, ChatGPT 등이 여기에 해당
슬라이드 5 도입 — 왜 바이브 코딩을 배울까? (이론 페이지)
* 기존 코딩: 프로그래밍 언어 문법을 공부 → 한 글자라도 틀리면 에러 → 진입 장벽이 높음
* 바이브 코딩: 아이디어만 있으면 AI에게 말로 설명 → AI가 코드 작성 → 결과물이 바로 나옴
* 하지만! 바이브 코딩에서 가장 중요한 건 코드가 아니라 "기획력"
* 내가 뭘 만들고 싶은지 명확히 아는 것
* AI에게 어떻게 설명할지 정리하는 것
* AI가 만든 결과물이 맞는지 확인하는 것
* 오늘의 핵심 메시지: AI는 도구이고, 여러분이 기획자이자 감독입니다!
슬라이드 6 이론 — Gemini 소개 (이론 페이지)
* 소요시간: 이론 15분 중 전반부
* Gemini란?
* 구글(Google)이 만든 AI 대화 모델
* 텍스트, 이미지, 코드 등을 이해하고 생성할 수 있음
* 우리가 한국어로 말해도 알아듣고, 코드도 만들어줌
* Gemini 모델 종류 (간단히):
* Gemini Flash: 빠르고 가벼움 — 간단한 작업에 적합 (우리 수업에서 주로 사용)
* Gemini Pro: 더 똑똑하고 정교함 — 복잡한 작업에 적합
* 쉬운 풀이 박스:
* 모델(Model) = AI의 두뇌에 해당하는 프로그램. 종류마다 성능과 속도가 다름
* 토큰(Token) = AI가 글을 이해하는 단위. 대략 한국어 한 글자가 1~2토큰 정도
슬라이드 7 이론 — Google AI Studio 소개 (이론 페이지)
* Google AI Studio란?
* 구글이 무료로 제공하는 AI 실험실(웹사이트)
* 브라우저에서 바로 Gemini에게 말을 걸고, 코드를 만들어달라고 할 수 있는 공간
* 별도 설치 없이 구글 계정만 있으면 바로 사용 가능
* 화면 구성 안내 (스크린샷 또는 그림 포함 권장):
* 왼쪽: 프롬프트 입력 영역 — 여기에 AI에게 할 말을 적는다
* 오른쪽: 결과 출력 영역 — AI가 생성한 답변이 나타나는 곳
* 상단: 모델 선택 — 어떤 AI 모델을 사용할지 고르는 곳
* 시스템 인스트럭션(System Instruction) — AI에게 "너는 OO역할이야"라고 미리 설정하는 곳
* 쉬운 풀이 박스:
* 프롬프트(Prompt) = AI에게 보내는 질문이나 명령. "이것 좀 만들어줘"라고 쓰는 그 문장 자체
* 시스템 인스트럭션(System Instruction) = AI에게 미리 부여하는 역할이나 규칙. "너는 친절한 웹 개발자야"처럼 AI의 성격을 설정하는 것

슬라이드 13 실습 2 — 나만의 자기소개 카드 만들기 (실습 페이지)
* 제목: AI에게 말해서 "내 자기소개 카드" 만들기! (30분)
* 목표: Gemini에게 프롬프트를 입력해서 HTML 자기소개 카드 코드를 받고, 브라우저에서 실행해보기
* 쉬운 풀이 박스:
* HTML = 웹페이지를 만드는 언어. 브라우저가 읽을 수 있는 설계도라고 생각하면 된다
* CSS = 웹페이지를 예쁘게 꾸미는 언어. 색상, 글꼴, 배치 등을 담당
* 코드 실행하기 = AI가 만들어준 코드를 복사해서 브라우저에서 열어보는 것
슬라이드 14 실습 2 — 프롬프트 작성 가이드 (실습 페이지)
* 자기소개 카드 프롬프트 예시:
나를 소개하는 예쁜 HTML 자기소개 카드 웹페이지를 만들어줘.
내 정보:
* 이름: 홍길동
* 학교: OO고등학교 1학년
* 취미: 농구, 음악 듣기
* 좋아하는 색: 파란색
* 한마디: "오늘도 화이팅!"
디자인 요청:
* 배경은 파란 계열 그라데이션
* 카드 형태로 가운데 정렬
* 이모지를 적절히 넣어줘
* 모서리는 둥글게
* HTML, CSS를 한 파일에 작성해줘
* 포인트: 이 프롬프트에는 "정보 + 디자인 요청"이 모두 포함되어 있다. 자기 정보와 원하는 디자인을 구체적으로 쓸수록 결과가 좋아진다!
슬라이드 15 실습 2 — 코드 실행하는 방법 (실습 페이지)
* AI가 코드를 만들어주면:
* 방법 A (Google AI Studio 내): AI Studio에 미리보기 기능이 있다면 바로 실행
* 방법 B (직접 실행):
* 1단계: AI가 만들어준 코드를 전체 복사 (Ctrl+A → Ctrl+C)
* 2단계: 메모장(Notepad)을 열고 붙여넣기 (Ctrl+V)
* 3단계: "다른 이름으로 저장" → 파일 이름을 "mycard.html"로 저장
* 4단계: 저장한 파일을 크롬 브라우저로 열기 (파일을 브라우저 창에 끌어다 놓기)
* 5단계: 짠! 내 자기소개 카드가 화면에 나타남!
* 강사 유의사항: 파일 저장 시 확장자가 .txt가 아닌 .html이 되도록 안내. 메모장에서 "파일 형식"을 "모든 파일"로 바꿔야 함을 시연한다.
