## 🌐 배포란 무엇인가?

### 배포(Deploy)의 개념

==배포(Deploy)== 란, 지금까지 내 컴퓨터에서만 열리는 `.html` 파일을 인터넷에 올려서, 누구나 링크(URL)를 통해 접속할 수 있게 만드는 것이다.

> 비유: 집에서 혼자 보던 그림을 갤러리에 전시하는 것!

배포를 하면 → 친구에게 링크를 보내면 → 친구가 폰이나 컴퓨터에서 바로 내 앱을 써볼 수 있다.

### 📖 용어 정리

| 용어 | 쉬운 풀이 |
|------|-----------|
| ==배포(Deploy)== | 만든 앱을 인터넷에 올려서 누구나 접속할 수 있게 하는 것 |
| ==호스팅(Hosting)== | 웹페이지 파일을 인터넷 서버에 올려두는 것. 서버가 24시간 켜져 있으니 언제든 접속 가능 |
| ==URL== | 인터넷 주소. 예: `https://내이름.netlify.app` |

## 🚀 무료 배포 따라하기

### 방법 A: Netlify Drop (가장 쉬움, 추천)

1. 브라우저에서 `app.netlify.com/drop` 접속
2. 내 `.html` 파일을 화면의 업로드 영역에 끌어다 놓기 (드래그 앤 드롭)
3. 몇 초 기다리면 자동으로 URL이 생성됨!
4. 생성된 URL을 복사해서 브라우저에 붙여넣기 → 내 앱이 인터넷에서 열리는지 확인
5. 이 URL을 친구에게 카카오톡으로 보내면 친구도 내 앱을 쓸 수 있음!

!!장점: 계정 없이도 가능, 30초면 끝!!

> 참고: 무료 계정은 일정 기간 후 사이트가 비활성화될 수 있다. 계속 유지하려면 Netlify 계정 가입(무료)이 필요하다.

### 방법 B: GitHub Pages (계정 필요, 영구 무료)

GitHub 계정이 있는 경우에 활용할 수 있는 방법이다.

1. `github.com`에서 새 저장소(Repository) 만들기 (이름 예: `my-app`)
2. `.html` 파일을 `index.html`로 이름 바꾸기
3. 저장소에 파일 업로드
4. Settings → Pages → Branch를 `main`으로 선택 → Save
5. 몇 분 후 `https://내아이디.github.io/my-app` 으로 접속 가능

### 방법 C: Google AI Studio 내 배포 기능

Google AI Studio에서 직접 미리보기/배포 기능을 제공하는 경우 이를 활용할 수 있다. 가능 여부를 먼저 확인해보자.

### 배포 성공 체크

- URL이 생성되었는가?
- URL을 브라우저에 입력하면 내 앱이 열리는가?
- 스마트폰에서도 접속되는가? (폰으로 직접 접속해보기)
- 모든 기능이 정상 동작하는가?

생성된 URL은 활동지에 꼭 기록해두자!

## 🤖 AI를 쓸 때 꼭 알아야 할 것들

### 환각 현상(Hallucination)

==환각(Hallucination)== 이란, AI가 마치 사실인 것처럼 그럴듯하게 말하지만, 실제로는 틀린 정보를 만들어내는 현상이다.

**예시:**
- "이 약은 감기에 효과가 있습니다"라고 AI가 말했지만 실제로는 검증되지 않은 정보
- AI가 만든 코드가 겉보기에 멀쩡하지만, 특정 상황에서 오류가 나는 경우

**왜 이런 일이 생기나?**

AI는 "가장 그럴듯한 다음 단어"를 예측해서 문장을 만드는 것이지, 진짜/거짓을 판단하는 것이 아니기 때문이다. AI는 거짓말을 "의도"하는 게 아니라, 그냥 확률적으로 그럴듯한 문장을 만들다 보니 발생하는 것이다.

**우리가 해야 할 것:**
- AI의 답변을 무조건 믿지 말고, 특히 사실관계(숫자, 날짜, 이름 등)는 반드시 직접 확인하기
- 코드도 마찬가지: AI가 만든 코드가 진짜 잘 동작하는지 직접 테스트해봐야 함 (6회차에 한 것!)

### 보안과 개인정보

**AI가 만든 코드의 보안 주의사항:**

- 비밀번호, 개인정보(이름, 전화번호, 주소 등)를 코드에 직접 넣으면 안 됨
- 예: 코드 안에 `password = "1234"` 같은 걸 넣으면 누구나 볼 수 있음
- ==배포한 웹앱의 코드는 누구나 F12를 눌러서 볼 수 있다==는 것을 기억!

**AI에게 개인정보를 입력할 때도 주의:**

- 프롬프트에 친구의 실명, 전화번호, 주소 등을 넣지 않는 것이 좋음
- AI 서비스에 입력한 내용이 학습 데이터로 사용될 수 있음
- "이 정보를 다른 사람이 본다면?" 항상 생각하기

### 편향성(Bias)과 저작권

**AI의 편향성:**

==편향(Bias)== 이란 AI가 특정 방향으로 치우친 결과를 내는 것이다. AI는 학습한 데이터에 있는 편견을 그대로 반영할 수 있다.

- 예: 특정 성별, 인종, 문화에 대한 고정관념이 결과에 나타날 수 있음
- 예: "CEO의 이미지를 그려줘"라고 하면 특정 성별/인종만 나올 수 있음
- AI가 만든 결과에 편향이 있는지 주의 깊게 살펴보는 자세가 필요

**저작권:**

==저작권(Copyright)== 이란 창작물에 대한 법적 권리다. "내가 만든 것"을 다른 사람이 함부로 쓸 수 없게 보호하는 것이다.

- AI가 만든 코드/디자인의 저작권은 아직 법적으로 완전히 정리되지 않은 영역
- AI가 만든 결과물이 다른 사람의 작품과 너무 비슷하지 않은지 확인할 필요 있음
- 바이브 코딩으로 만든 앱을 상업적으로 사용하려면 이 부분을 더 공부해야 함
- 학교 과제나 개인 프로젝트 수준에서는 "이건 AI가 도와줬다"는 것을 밝히는 것이 올바른 태도

## 🎤 발표 시간

### 발표 구성

한 명당 3~5분, 아래 순서로 발표한다.

1. 앱 이름 & 한 줄 소개
2. 앱 시연 (실제로 동작하는 모습 보여주기)
3. 가장 어려웠던 순간 & 어떻게 해결했는지
4. 가장 자랑하고 싶은 프롬프트 1개 소개

발표 후에는 친구들의 질문 또는 응원 한마디를 나눈다.

> 이 시간은 비판이나 평가가 아니라 "자랑과 축하"의 시간이다. "코드를 잘 짰느냐"가 아니라 "아이디어를 실현했느냐"에 초점을 맞추자.

## ✅ 오늘의 핵심 정리

1. ==배포(Deploy)== = 내 `.html` 파일을 인터넷에 올려 누구나 링크로 접속할 수 있게 하는 것. Netlify Drop을 사용하면 30초 만에 가능하다.
2. ==환각(Hallucination)== = AI가 사실이 아닌 내용을 그럴듯하게 생성하는 현상. AI의 답변을 맹목적으로 믿지 말고 중요한 정보는 직접 확인하자.
3. ==편향(Bias)== = AI가 학습 데이터의 편견을 반영해 치우친 결과를 내는 것. 결과를 비판적으로 살펴보는 자세가 필요하다.
4. 배포한 웹앱의 코드는 누구나 볼 수 있으므로 개인정보나 비밀번호를 코드에 넣으면 안 된다.
5. AI 시대의 현명한 사용자가 되는 5가지 원칙: **확인하기 · 보호하기 · 의심하기 · 밝히기 · 결정하기**

> AI 시대에 가장 중요한 건 코딩 실력이 아니라 **'무엇을 만들고 싶은지 아는 것'**이다. 여러분은 이미 그 능력을 가지고 있다.
