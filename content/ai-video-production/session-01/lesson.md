# AI로 나만의 영상 제작하기

> **오늘의 핵심 메시지:** 아이디어 기획부터 편집, 배경음악까지 AI 도구를 연결하면 영상 제작의 진입장벽을 크게 낮출 수 있다.

---

## 도입: 강의 개요와 오늘 배우는 것

이번 교안은 `ChatGPT + VREW + Suno AI`를 연결해 하나의 짧은 영상을 만드는 흐름을 다룹니다.  
핵심은 `좋은 기획 -> 구체적인 프롬프트 -> 쉬운 편집 -> 분위기에 맞는 음악 추가` 순서로 작업하는 것입니다.

| 구분 | 내용 |
|------|------|
| 강의 주제 | AI로 나만의 영상 제작 |
| 다루는 도구 | ChatGPT, VREW, Suno AI |
| 학습 흐름 | 영상 스토리 기획 -> 프롬프트 작성 -> VREW 편집 -> 배경음악 제작 |
| 기대 결과 | 아이디어가 있는 입문자도 짧은 영상 초안을 스스로 완성할 수 있음 |

### 오늘 배우는 것

- AI를 활용해 영상 아이디어와 스토리라인을 구상하는 방법
- 더 좋은 결과를 얻는 프롬프트 작성법
- VREW로 자막과 영상을 손쉽게 편집하는 기본 흐름
- Suno AI로 배경음악을 만들고 영상에 삽입하는 방법

---

## 섹션 1: AI 활용 영상 기획

영상 제작은 바로 편집부터 시작하지 않습니다. 먼저 `무엇을 누구에게 어떤 흐름으로 보여줄지`를 정리해야 합니다.

### AI 활용 영상 기획 단계

| 단계 | 설명 |
|------|------|
| 주제 선정 | 여행, 취미, 요리, 건강 등 만들고 싶은 영상 주제를 정함 |
| 콘텐츠 구상 | 어떤 장면과 메시지를 넣을지 큰 그림을 잡음 |
| 영상 구성안 작성 | 도입부, 중간부, 마무리 순서로 흐름을 설계함 |
| 대본 작성 | 실제 자막이나 내레이션으로 쓸 문장을 준비함 |
| 세부 요소 추가 | 자막, 화면 전환, 분위기, 음악 등 디테일을 보완함 |

### AI에게 맡길 수 있는 기획 작업

| 요청 유형 | AI가 도와주는 내용 |
|-----------|-------------------|
| 주제 아이디어 추천 | 어떤 소재가 영상으로 적합한지 제안 |
| 영상 구성 요소 제안 | 장면, 자막, 설명 포인트 추천 |
| 스토리라인 구체화 | 시작, 전개, 마무리 구조 정리 |
| 대본 초안 작성 | 소개 멘트, 설명 문장, 자막 문구 작성 |
| 콘텐츠 문장화 | 영상 속 핵심 메시지를 자연스러운 문장으로 변환 |

> 핵심은 AI에게 막연히 "영상 만들어줘"라고 하는 것이 아니라, 기획 보조 도구처럼 구체적인 역할을 주는 것입니다.

## 섹션 2: 좋은 프롬프트 구성 요소와 개선 예시

좋은 프롬프트는 보통 `목적`, `컨텍스트`, `형식 지정`이 들어갑니다.

### 프롬프트 구성 요소

| 요소 | 의미 | 예시 |
|------|------|------|
| 목적 | 무엇을 만들고 싶은지 | "여행 브이로그 영상을 만들고 싶어요." |
| 컨텍스트 | 누구를 위한 어떤 상황인지 | "제주도 3박 4일 여행을 다녀왔고, 50대 여성을 위한 콘텐츠입니다." |
| 형식 지정 | 어떤 형태로 결과를 원하는지 | "5분 분량의 브이로그 구성안을 단계별로 알려주세요." |

### 프롬프트 개선 예시

| 구분 | 예시 | 결과 |
|------|------|------|
| 효과 낮음 | "요리 영상 만들어줘" | 주제, 대상, 길이, 분위기가 없어 결과가 모호함 |
| 효과 높음 | "60대 초보를 위한 3분 길이의 간단한 건강 요리법 영상 구성안 알려줘." | 목적과 시청자, 길이가 분명해 훨씬 구체적인 결과를 얻기 쉬움 |

### 영상 기획 프롬프트 예시

```prompt
나는 취미로 도자기를 만드는 50대 남성입니다.
내 작품을 소개하는 3분짜리 영상을 만들고 싶어요.
같은 취미를 가진 시니어층을 대상으로 합니다.
차분하고 전문적인 느낌으로 영상 구성안을
도입부, 중간부, 마무리 섹션으로 나누어 알려주세요.
```

> 좋은 프롬프트에는 `명확한 목적`, `대상`, `분량`, `원하는 분위기`가 포함됩니다.

## 섹션 3: 영상 기획 프롬프트 템플릿

교안에서는 상황별로 바로 복사해 쓸 수 있는 템플릿을 제시합니다.

### 개인 경험·일상

```prompt
나는 [나이/성별]이고, [활동/경험]에 대한 [영상 길이] 영상을 만들고 싶어요.
[목표 시청자]를 위한 영상 구성을 알려주세요.
```

### 장소·상품 리뷰

```prompt
[장소/상품명]에 대한 리뷰 영상을 만들고 싶어요.
[좋았던 점/아쉬운 점]을 중심으로 [영상 길이] 분량의
영상 스크립트를 작성해주세요.
```

### 취미·지식 공유

```prompt
[취미/주제]에 대한 초보자 가이드 영상을 만들고 싶어요.
[타겟 시청자]가 쉽게 이해할 수 있는 [영상 길이] 분량의
단계별 구성을 알려주세요.
```

### 일상 브이로그

```prompt
내 [일상/특별한 날]을 담은 브이로그를 만들고 싶어요.
[주요 활동 3~4가지]를 포함해서 [분위기] 느낌의
영상 구성안을 알려주세요.
```

| 템플릿 활용 팁 | 설명 |
|----------------|------|
| 길이 먼저 정하기 | 1분, 3분, 5분처럼 분량을 정하면 결과가 안정적임 |
| 타겟 시청자 넣기 | 연령대와 관심사를 넣으면 설명 톤이 달라짐 |
| 분위기 지정하기 | 차분한, 밝은, 따뜻한 같은 분위기 단어가 유용함 |
| 핵심 내용 제한하기 | 3~5개 정도의 포인트만 요청하면 정리가 쉬움 |

## 섹션 4: 실습 단계 1-3

이 파트는 학습자가 직접 영상 기획 프롬프트를 만드는 연습입니다.

### 1단계: 주제 선택하기

만들고 싶은 영상 주제를 하나 고릅니다.

| 예시 주제 |
|-----------|
| 여행 |
| 취미 |
| 요리 |
| 건강 |
| 일상 기록 |

### 2단계: 프롬프트 요소 정리하기

아래 항목을 먼저 메모하면 프롬프트 작성이 훨씬 쉬워집니다.

| 정리 항목 | 예시 |
|-----------|------|
| 대상 시청자 | 50대 여성, 시니어층, 초보자 |
| 영상 길이 | 3분, 5분 |
| 영상 목적 | 정보 전달, 추억 공유, 리뷰 |
| 포함할 내용 | 핵심 장면 3~5개, 전달할 메시지 |

### 3단계: 프롬프트 작성하기

```prompt
나는 [나이/성별]이고, [주제]에 대한 영상을 만들고 싶어요.
[길이]분량으로 [핵심 내용]을 포함해 주세요.
```

> 처음부터 완벽하게 쓰지 않아도 됩니다. 한 번 작성한 뒤 AI 응답을 보고 조금씩 수정하면 됩니다.

## 섹션 5: VREW 소개와 주요 기능

`VREW`는 초보자도 쉽게 쓸 수 있도록 설계된 영상 편집 프로그램입니다.  
특히 `자동 자막 생성`과 `간단한 컷 편집` 기능이 강점입니다.

### VREW 한줄 소개

자동 자막 생성과 간편한 영상 편집이 가능한 초보자 친화형 프로그램입니다.  
영상 속 음성을 인식해 자막을 만들고, 필요한 부분만 골라 편집할 수 있습니다.

### 주요 기능

| 기능 | 설명 |
|------|------|
| 자동 자막 생성 | 영상 속 음성을 분석해 자막을 자동으로 만듦 |
| 간단한 컷 편집 | 필요 없는 부분을 선택해서 쉽게 잘라낼 수 있음 |
| 무료 소스 활용 | 이미지, 영상 클립, 배경음악, 폰트, 자막 템플릿 제공 |
| 텍스트 기반 영상 제작 | 대본을 입력하면 AI가 영상 요소를 조합해 초안을 생성 |

> 교안의 핵심 포인트는 `복잡한 편집 기술 없이도 텍스트와 자막 중심으로 영상을 완성할 수 있다`는 점입니다.

## 섹션 6: VREW 기본 사용 방법

### 시작하기

| 단계 | 설명 |
|------|------|
| 1 | [VREW 공식 사이트](https://vrew.ai)에 접속 |
| 2 | 무료 다운로드 클릭 |
| 3 | 회원가입 후 프로그램 실행 |

![VREW 새 프로젝트 시작 화면](/images/ai-video-production/session-01/vrew-new-project.png)

*VREW를 실행하면 새 프로젝트를 만드는 화면에서 `텍스트로 비디오 만들기`를 선택할 수 있습니다.*

### 텍스트로 영상 만들기

VREW에서는 `텍스트로 비디오 만들기` 기능으로 영상 초안을 빠르게 만들 수 있습니다.

| 입력 항목 | 설명 |
|-----------|------|
| 대본 | 직접 쓰거나 AI가 생성한 스크립트를 입력 |
| 스타일 | 뉴스, 다큐, 교육 등 원하는 톤 선택 |
| AI 목소리 | 내레이션 톤에 맞는 음성 선택 |
| 배경음악 | 기본 음악 또는 외부 음악 설정 |

### 교안 기준 작업 흐름

1. `텍스트로 비디오 만들기` 버튼을 누릅니다.
2. 준비한 대본을 입력합니다.
3. 스타일을 바로 시작하거나 추천 비디오 스타일을 선택합니다.
4. `주제`를 입력하고 AI 글쓰기를 실행하면 GPT 기반으로 대본 초안을 만들 수 있습니다.
5. 생성된 영상 초안을 확인한 뒤 필요한 부분을 수정합니다.

![VREW AI 글쓰기 화면](/images/ai-video-production/session-01/vrew-ai-writing.png)

*교안에 나온 것처럼 주제와 말투, 글자 수를 넣으면 AI 글쓰기로 대본 초안을 생성할 수 있습니다.*

### 편집 포인트

| 편집 항목 | 설명 |
|-----------|------|
| 자막 편집 | 자막 문장, 띄어쓰기, 줄바꿈 수정 |
| 대사 편집 | 내레이션 문장을 더 자연스럽게 다듬기 |
| 스타일 조정 | 영상 분위기와 정보 전달 목적에 맞게 선택 변경 |

![VREW 편집 화면](/images/ai-video-production/session-01/vrew-editing.png)

*생성된 영상은 자막 단위로 문장을 다듬고, 화면 왼쪽 미리보기와 함께 편집 흐름을 확인할 수 있습니다.*

## 섹션 7: 배경음악 삽입

영상 분위기를 정리하는 마지막 단계 중 하나가 배경음악 삽입입니다.

### VREW에서 배경음악 넣는 순서

1. `삽입`
2. `배경음악`
3. `PC에서 불러오기`
4. 원하는 음악 선택
5. `삽입하기`

| 체크 포인트 | 설명 |
|-------------|------|
| 음악 볼륨 | 자막이나 내레이션을 방해하지 않게 조절 |
| 분위기 일치 | 여행, 정보성, 브이로그 등 영상 톤과 맞추기 |
| 길이 확인 | 영상 길이에 맞게 반복 또는 트리밍 필요 여부 확인 |

![VREW 배경음악 삽입 화면](/images/ai-video-production/session-01/vrew-bgm-import.png)

*배경음악 메뉴에서 `PC에서 불러오기`를 선택하면 직접 만든 음악이나 저장된 음원을 추가할 수 있습니다.*

> 배경음악은 너무 튀기보다, 영상 메시지를 자연스럽게 받쳐주는 수준이 가장 안정적입니다.

## 섹션 8: Suno AI로 음악 만들기

교안 마지막 파트는 `Suno AI`를 이용해 나만의 배경음악을 만드는 방법입니다.

### Suno AI 소개

| 항목 | 내용 |
|------|------|
| 서비스명 | Suno AI |
| 역할 | 인공지능 음악 생성 플랫폼 |
| 접속 주소 | [https://suno.com](https://suno.com) |
| 가입 방식 | `Sign up` 클릭 후 구글 계정 또는 이메일 로그인 |

![Suno AI 홈 화면](/images/ai-video-production/session-01/suno-home.png)

*로그인 후에는 홈 화면에서 바로 음악 생성 메뉴로 이동하거나 최근 작업을 확인할 수 있습니다.*

### 사용 포인트

| 항목 | 설명 |
|------|------|
| 무료 사용 | 기본 기능은 무료로 사용 가능 |
| 생성량 | 하루 약 10곡 정도 생성 가능 |
| 1회 생성 | 한 번에 2곡 생성 |
| 입력 방식 | 만들고 싶은 음악 분위기를 프롬프트로 작성 |

### 배경음악 프롬프트 예시

```prompt
따뜻하고 차분한 분위기의 브이로그 배경음악을 만들어줘.
어쿠스틱 기타 중심이고, 너무 빠르지 않은 템포로,
여행 영상에 어울리는 편안한 느낌이면 좋겠어.
```

![Suno AI 생성 화면](/images/ai-video-production/session-01/suno-create.png)

*생성 화면에서는 프롬프트를 직접 입력하고, 장르 태그나 Instrumental 옵션을 조정한 뒤 음악을 만들 수 있습니다.*

### 활용 흐름

1. Suno에서 음악을 생성합니다.
2. 마음에 드는 곡을 다운로드합니다.
3. VREW에서 `삽입 > 배경음악 > PC에서 불러오기`로 가져옵니다.
4. 영상 길이와 분위기에 맞게 배치합니다.

## 마무리: 핵심 정리와 다음 행동

### 오늘의 핵심 정리

1. 영상 제작은 편집보다 `기획`이 먼저다.
2. 좋은 프롬프트에는 목적, 대상, 길이, 형식이 들어간다.
3. VREW는 초보자도 자막과 컷 편집을 빠르게 다룰 수 있게 해준다.
