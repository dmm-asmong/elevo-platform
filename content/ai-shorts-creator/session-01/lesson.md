# AI 3종 세트로 숏폼 영상 완성하기 🎬

> **"아이디어만 있으면 AI가 나머지를 한다 — 기획·촬영·편집 모두"**  
> ==ChatGPT/Gemini==로 대본을 쓰고, ==Google Flow==로 영상 클립을 만들고, ==Vrew==로 완성하는 풀 파이프라인을 90분 안에 경험한다.

---

## AI 파이프라인 한눈에 보기

| 단계 | 도구 | 역할 | 결과물 |
|:---:|---|---|---|
| **1️⃣ 기획** | ChatGPT 또는 Gemini | 주제 선정 → 60~90초 대본 생성 → 이미지 프롬프트 추출 | 대본 + 이미지 프롬프트 3개 |
| **2️⃣ 시각화** | Google Flow | 프롬프트 기반 이미지·영상 클립 생성 | 영상 클립 3~5개 |
| **3️⃣ 편집** | Vrew | 클립 배열 → 자막 생성 → BGM·전환 → 세로형 export | 완성된 숏폼 영상 1편 |

> 💡 세 도구 모두 무료로 시작할 수 있다. 계정만 있으면 바로 실습 가능!

## Step 1 — 🤖 AI로 기획하기 (20분)

### 주제, 어디서 찾을까?

==숏폼==은 짧고 강렬해야 한다. 가장 좋은 주제는 **이미 내가 아는 것**이다.

| 질문 | 예시 답변 → 주제 |
|---|---|
| 요즘 내가 가장 자주 하는 것은? | 카페 탐방 → "요즘 뜨는 카페 스타일 TOP 3" |
| 친구들에게 자주 설명하는 것은? | 공부법 → "벼락치기 말고 이렇게 해봐" |
| 최근에 감동받거나 신기했던 것은? | 새 앱 발견 → "이 앱 진짜 몰랐지?" |
| 내가 잘하는 것, 취미는? | 드로잉 → "5분 만에 캐릭터 그리는 법" |

> 💡 완벽한 주제를 고를 필요 없다. 오늘 실습용이니까 **일단 하나 고르고 시작**하자.

---

### ChatGPT / Gemini에게 대본 요청하기

아래 프롬프트를 복사해서 바로 붙여넣어 보자.

```prompt
너는 유튜브 쇼츠·릴스·틱톡 전문 크리에이터야.
내 주제는 [나의 주제]야.
시청 대상: [10~20대 학생 / 직장인 등 타겟]

아래 조건에 맞게 숏폼 대본을 작성해줘:
- 총 길이: 60~90초 분량 (약 150~200자)
- 구성: 훅(Hook) → 핵심 내용 3가지 → 마무리 CTA
- 말투: 친근하고 자연스러운 구어체
- 각 파트를 [훅], [내용1], [내용2], [내용3], [CTA] 태그로 구분해서 작성해줘
```

#### 대본 예시 결과

> **주제:** 벼락치기 말고 이렇게 해봐

```
[훅] 시험 3일 전에도 A+ 받는 방법 알아? 비밀 공개할게.
[내용1] 첫째, 교과서 대신 기출문제부터 봐. 출제 패턴이 보여.
[내용2] 둘째, 요약 노트 쓰지 마. 대신 핵심 키워드만 소리 내서 읽어.
[내용3] 셋째, 공부 30분 하면 5분 무조건 쉬어. 집중력이 2배야.
[CTA] 이거 써봤다면 댓글에 알려줘. 팔로우하면 다음 꿀팁 놓치지 않을 수 있어!
```

---

### 대본에서 이미지 프롬프트 추출하기

대본이 완성되면, 이 프롬프트로 시각화 재료를 뽑아낸다.

```prompt
위 대본을 바탕으로 Google Flow(AI 이미지·영상 생성 도구)에 입력할
이미지/영상 프롬프트 3개를 영어로 만들어줘.

조건:
- 각 프롬프트는 30단어 이내
- 숏폼(세로형 9:16) 영상에 어울리는 시각적 장면 묘사
- 실사 스타일 또는 밝고 깔끔한 일러스트 스타일로
- 번호를 붙여서 리스트로 작성해줘
```

#### 추출 결과 예시 테이블

| 번호 | 장면 (대본 파트) | 영어 이미지 프롬프트 |
|:---:|---|---|
| 1 | 훅 — 시험 3일 전 | Student looking at calendar with 3 days circled, determined expression, bright study room, 9:16 vertical |
| 2 | 내용1 — 기출문제 | Open past exam papers on a clean desk, highlighter marks, focused top-down shot, minimal style |
| 3 | CTA — 팔로우 유도 | Young person smiling at camera, thumbs up, colorful modern background, vertical format |

## Step 2 — 🎨 Google Flow로 시각화하기 (20분)

### Google Flow란?

==Google Flow==는 Google DeepMind가 만든 AI 영상·이미지 생성 플랫폼이다.  
텍스트 프롬프트를 입력하면 **수초 안에 고품질 비주얼 클립**을 만들어준다.

| 항목 | 내용 |
|---|---|
| 접속 주소 | [flow.google.com](https://flow.google.com) |
| 가입 방식 | Google 계정 로그인 |
| 무료 사용 | 제한된 생성 횟수 무료 제공 |
| 출력 형식 | 이미지 또는 짧은 영상 클립 (MP4) |

---

### 사용 방법 — 4단계

**1. 접속 & 로그인**
- [flow.google.com](https://flow.google.com)에 접속한다.
- Google 계정으로 로그인한다.

**2. 프롬프트 입력**
- 홈 화면의 텍스트 입력창에 Step 1에서 추출한 **영어 프롬프트**를 붙여넣는다.
- 스타일 옵션(사실적·일러스트·시네마틱 등)을 선택한다.

**3. 생성 & 확인**
- `Generate` 버튼을 클릭하면 이미지 또는 영상 클립이 생성된다.
- 한 번에 여러 변형이 만들어지므로 가장 마음에 드는 것을 고른다.

**4. 선택 & 다운로드**
- 원하는 클립을 클릭하고 `Download`를 눌러 저장한다.
- 프롬프트 3개 모두 반복해서 클립 3~5개를 확보한다.

---

### 좋은 클립 고르는 팁

| 체크 항목 | 기준 |
|---|---|
| 피사체가 선명한가? | 주인공이 흐리거나 이상하게 변형되지 않았는지 확인 |
| 세로형(9:16)에 어울리는가? | 가로로 넓게 펼쳐진 구도보다 세로 중심 구도가 유리 |
| 대본 내용과 연결되는가? | 클립만 봐도 "어떤 내용인지" 느껴지면 합격 |
| 색감이 통일되어 있는가? | 클립들의 전체 분위기가 비슷하면 편집이 훨씬 자연스럽다 |

> ⚠️ **저작권 안내:** Google Flow로 생성된 이미지·영상은 AI가 직접 생성한 콘텐츠로, 타인의 저작물을 직접 복제하지 않는다. 단, 플랫폼 약관을 확인하고 상업적 사용 전에는 이용 정책을 꼭 검토하자.

## Step 3 — ✂️ Vrew로 편집 완성하기 (30분)

### Vrew란?

==Vrew==는 자막 자동 생성과 간편한 컷 편집에 특화된 영상 편집 프로그램이다.  
이전 강의(AI 영상 제작 입문)에서도 활용했던 도구로, 오늘은 **숏폼 세로형 영상 완성**에 집중한다.

| 항목 | 내용 |
|---|---|
| 다운로드 | [vrew.ai](https://vrew.ai) → 무료 다운로드 |
| 핵심 강점 | 자막 자동 생성 + 무료 BGM + 세로형 export |
| 오늘 사용 목적 | Google Flow 클립 → 자막 → BGM → 9:16 완성 |

---

### 단계별 편집 과정

#### 1️⃣ 클립 가져오기 & 배열

1. Vrew를 실행하고 `새 프로젝트`를 만든다.
2. `파일에서 불러오기`로 Google Flow에서 다운로드한 클립들을 불러온다.
3. 대본 순서(훅 → 내용1 → 내용2 → 내용3 → CTA)에 맞게 클립을 타임라인에 배열한다.

> 💡 클립이 대본보다 짧으면 같은 클립을 반복 배치하거나, Flow에서 추가로 생성해서 채운다.

#### 2️⃣ 자막 자동 생성 → 대본에 맞게 수정

1. 상단 메뉴 `자막` → `자막 자동 생성`을 클릭한다.
2. 음성이 없는 영상이라면 `텍스트로 자막 추가`를 선택해 대본 문장을 직접 입력한다.
3. 생성된 자막을 대본과 대조하며 오탈자·띄어쓰기를 수정한다.
4. 자막 스타일(폰트, 크기, 색상, 위치)을 숏폼에 맞게 조정한다. — 굵은 폰트, 밝은 색상 추천.

#### 3️⃣ BGM 추가 (Vrew 내장 무료 음악)

1. `삽입` → `배경음악` → `Vrew 음악 라이브러리`를 선택한다.
2. 영상 분위기에 맞는 트랙을 고른다. (밝은 팝·로파이·어쿠스틱 등)
3. 볼륨은 자막/내레이션을 방해하지 않도록 **20~30% 수준**으로 낮춘다.

#### 4️⃣ 장면 전환 효과

1. 타임라인에서 클립과 클립 사이 **연결점**을 클릭한다.
2. 전환 효과 메뉴에서 숏폼에 어울리는 스타일을 선택한다. — `페이드`, `슬라이드`, `줌인` 추천.
3. 효과 시간은 **0.3~0.5초**가 자연스럽다. 너무 길면 템포가 느려진다.

#### 5️⃣ 세로형(9:16) Export 설정

1. `내보내기` 버튼을 클릭한다.
2. 해상도에서 `세로형 (1080 × 1920)` 또는 `9:16`을 선택한다.
3. 포맷은 `MP4`, 품질은 `고화질`로 설정 후 내보내기를 완료한다.

---

### 완성 체크리스트

| 항목 | 확인 |
|---|:---:|
| 클립이 대본 순서대로 배열되어 있다 | ☐ |
| 자막이 모든 장면에 표시된다 | ☐ |
| 자막에 오탈자가 없다 | ☐ |
| BGM이 삽입되고 볼륨이 적당하다 | ☐ |
| 클립 간 전환 효과가 적용되어 있다 | ☐ |
| Export 해상도가 9:16(세로형)이다 | ☐ |
| 완성 파일을 재생하여 처음부터 끝까지 확인했다 | ☐ |

## 📦 챙겨가기 — 프롬프트 템플릿 모음

이 섹션은 강의 이후 혼자 숏폼을 제작할 때 **바로 복붙**해서 쓸 수 있는 템플릿 모음이다.  
`[대괄호]` 안의 내용만 바꿔서 사용하자.

---

### 템플릿 1 — 숏폼 주제 추천

처음 주제를 정할 때 막막하다면 AI에게 먼저 물어보자.

```prompt
나는 [나의 관심사 / 취미 / 전공]에 관심 있는 [나이대] 학생이야.
유튜브 쇼츠나 인스타 릴스용 숏폼 영상 주제를 10개 추천해줘.

조건:
- 60~90초 안에 완성할 수 있는 주제
- 촬영 없이 AI 생성 이미지로만 만들 수 있는 내용
- 요즘 트렌디하고 10~20대가 관심 가질 만한 것 위주로
- 주제마다 한 줄 설명도 붙여줘
```

---

### 템플릿 2 — 60초 숏폼 대본 생성

주제가 정해졌다면 대본을 바로 뽑아보자.

```prompt
너는 유튜브 쇼츠 전문 크리에이터야.
주제: [주제]
타겟: [타겟 시청자]

아래 구조로 60~90초 분량의 숏폼 대본을 작성해줘:
[훅] - 시청자를 멈추게 하는 첫 1~2문장 (질문형 또는 충격적 사실)
[내용1] - 핵심 포인트 첫 번째
[내용2] - 핵심 포인트 두 번째
[내용3] - 핵심 포인트 세 번째
[CTA] - 팔로우·좋아요·댓글 유도 문장

말투는 [친근한 / 전문적인 / 유머러스한] 구어체로 써줘.
전체 글자 수는 150~200자 이내로 제한해줘.
```

---

### 템플릿 3 — 이미지 생성용 프롬프트 추출

대본을 Google Flow에 바로 쓸 수 있는 영어 프롬프트로 변환한다.

```prompt
위 대본의 각 파트([훅], [내용1], [내용2], [내용3], [CTA])를 시각적으로 표현하는
Google Flow용 이미지·영상 프롬프트를 영어로 5개 작성해줘.

조건:
- 각 프롬프트는 20~30단어 이내
- 세로형(9:16) 숏폼에 어울리는 구도와 장면
- 스타일: [사실적인 실사 / 밝은 일러스트 / 시네마틱] 중 선택
- 인물이 등장할 경우 얼굴 표정과 감정을 명확히 묘사
- 프롬프트 앞에 [훅], [내용1] 같은 태그를 붙여줘
```

## 핵심 정리

1. ==기획==은 ChatGPT/Gemini로 — 훅·내용·CTA 구조의 대본을 60초 안에 완성할 수 있다.
2. ==시각화==는 Google Flow로 — 영어 프롬프트 3개면 영상 클립 세트가 완성된다.
3. ==편집==은 Vrew로 — 자막·BGM·전환·세로형 export까지 코딩 없이 클릭만으로 된다.
4. 세 도구를 연결하면 아이디어에서 완성 영상까지 **90분이면 충분하다**.

> **"첫 영상은 완벽하지 않아도 된다. 업로드하는 것 자체가 시작이다."** 🎬
