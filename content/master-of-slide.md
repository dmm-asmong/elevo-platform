## 개요

**Master of Slide**는 Markdown 또는 Obsidian 노트를 **React 기반 1920×1080 프레젠테이션**으로 자동 변환하는 AI 슬라이드 제작 도구입니다.  
`open-slide` 런타임을 기반으로, Claude Code의 `/slide` 명령 한 번으로 발표 자료를 완성합니다.  
**한국어 콘텐츠에 최적화**된 폰트 처리와 줄바꿈 규칙이 기본 탑재되어 있습니다.

## 설치

### 1. 리포지토리 클론 및 실행

```bash
git clone https://github.com/reallygood83/master-of-slide.git
cd master-of-slide
pnpm install
pnpm dev:demo
```

브라우저에서 `http://127.0.0.1:5173` 접속 → 슬라이드 미리보기 확인

### 2. Claude Code 에이전트 스킬 전역 등록

```bash
pnpm install:agents
```

등록 후 Claude Code에서 `/slide` 명령으로 즉시 사용 가능합니다.

### 3. 새 워크스페이스 생성 (CLI)

```bash
npx @open-slide/cli init my-presentation
cd my-presentation
pnpm dev
```

## 핵심 명령어: `/slide`

`/slide` 는 Markdown 파일을 슬라이드 덱으로 변환하는 메인 진입점입니다.

### 실행 전 Claude가 확인하는 항목

| 항목 | 기본값 |
|------|--------|
| 페이지 수 | 8 슬라이드 |
| 생성 이미지 수 | 2장 |
| 비주얼 테마 | 자동 추천 |

### 워크플로우

```
① 소스 Markdown 파일 읽기
② 생성 파라미터 사용자 확인
③ 콘텐츠 구조 파싱 + 메타데이터 추론
④ slides/<id>/index.tsx 에 React 컴포넌트 자동 생성
⑤ 이미지 복사 또는 AI 생성
⑥ 1920×1080 캔버스 및 텍스트 렌더링 검증
⑦ 미리보기 URL 제공: http://127.0.0.1:5173/s/<id>
```

### 사용 예시

```prompt
이 강의 노트를 슬라이드로 만들어줘.
```

```prompt
/slide
```

**Claude의 반응:**
> "슬라이드를 몇 장으로 만들까요? 이미지는 몇 개 생성할까요?"  
> 확인 후 → `slides/my-lecture/index.tsx` 자동 생성  
> → `http://127.0.0.1:5173/s/my-lecture` 에서 미리보기

## 스킬 구성

Master of Slide는 목적별로 분리된 4개의 전문 스킬을 제공합니다:

| 스킬 | 명령어 | 역할 |
|------|--------|------|
| 메인 변환 | `/slide` | Markdown → 슬라이드 덱 메인 진입점 |
| 상세 변환 | `create-slide-from-markdown` | `.md` 파일 → `open-slide` 덱 세부 구현 |
| 작성 레퍼런스 | `slide-authoring` | 슬라이드 기술 제약사항 및 규칙 |
| 이미지 프롬프트 | `create-slide-image-prompts` | AI 이미지 생성용 프롬프트 작성 |

## 캔버스 규칙 (핵심 제약사항)

슬라이드는 **고정 1920×1080px** 캔버스이며 반응형이 아닙니다.

```
⛔ 스크롤 없음 — 1080px 아래 내용은 자동으로 잘림
⛔ 반응형 단위 금지 (%, vw, vh)
✅ 절대 픽셀값 사용
✅ 수직 예산 계산 필수
```

**수직 예산 계산 공식:**
```
(font_size × line_height × lines) + gaps + padding ≤ 1080px
```

### 권장 타입 스케일

| 용도 | 크기 |
|------|------|
| 히어로 헤딩 | 140–200px |
| 페이지 헤딩 | 72px |
| 본문 | 32–44px |
| 캡션 | 22–28px |
| 콘텐츠 패딩 | 100–160px |

## 지원하는 Markdown 요소

`create-slide-from-markdown` 스킬이 자동으로 처리하는 Markdown 요소들:

| 요소 | 처리 방식 |
|------|----------|
| YAML frontmatter | 슬라이드 메타데이터 추출 |
| `#` 헤딩 | 슬라이드 구분 및 제목 |
| 리스트 / 문단 | 핵심 내용 요약 |
| Callout (`> [!note]`) | 강조 박스로 변환 |
| Wikilink (`[[페이지]]`) | 텍스트로 렌더링 |
| 이미지 / 동영상 | 에셋으로 임베딩 |
| 코드 블록 | 필요 시에만 포함 |
| 테이블 | 필요 시에만 포함 |

**한국어 처리:** `lang: 'ko'` 자동 설정, 한글 폰트 폴백, 줄바꿈 규칙 자동 적용

## 테마 시스템

총 9가지 비주얼 테마를 지원하며, 콘텐츠 분위기에 맞게 자동 추천됩니다:

| 테마 | 스타일 | 특징 |
|------|--------|------|
| `editorial-noir` | 다크 매거진 | 배경 `#0b0d10`, 앰버 포인트, 세리프 168px 히어로 |
| `neon-terminal` | 개발자 터미널 | 네온 컬러, 모노스페이스 폰트 |
| `paper-press` | 신문 인쇄 | 클래식 타이포그래피 |
| + 6개 추가 테마 | 매거진 / 리포트 / 포토 에디토리얼 | 상황에 맞게 선택 |

## 실전 팁

**1. Obsidian 노트 바로 변환**
```prompt
/slide
```
Obsidian 볼트의 노트를 `/slide` 에 붙여넣거나 파일 경로를 지정하면 바로 슬라이드로 변환됩니다.

**2. 테마 지정하기**
```prompt
neon-terminal 테마로 개발 발표 슬라이드 10장 만들어줘.
```

**3. 이미지 자동 생성**
```prompt
각 섹션에 맞는 이미지 3개 생성해서 슬라이드에 넣어줘.
```

**4. 기존 슬라이드 수정**
`@slide-comment` 마커를 사용해 인스펙터 코멘트를 적용하거나, `slide-authoring` 스킬로 세부 편집합니다.
