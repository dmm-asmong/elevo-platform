## STEP 1 — 주제 선정 & 스크립트 (Gemini)

### 내 영상 주제

> **주제:** _______________________________________________

### Gemini 프롬프트 (아래 칸에 직접 작성 후 Gemini에 입력하세요)

```
너는 유튜브 쇼츠 크리에이터야.
주제: [주제를 여기에]
대상: 중학생

아래 조건으로 숏폼 영상 자막 대본을 써줘:
- 장면 3개 구성 ([훅] → [내용] → [마무리+CTA])
- 각 장면 자막: 20자 이내
- 친근하고 재밌는 말투, 이모지 1개씩 포함
```

### Gemini가 써준 스크립트 (결과 붙여넣기 또는 직접 적기)

| 장면 2 (내용) | | |
| 장면 3 (마무리) | | |

> **팁:** AI 결과를 그대로 쓰지 말고, 내 말투로 최소 1문장 이상 수정해보세요!

## STEP 3 — Vrew 영상 자동 생성

**접속:** vrew.ai → **이미지로 비디오 만들기** → 9:16 세로형

| 순서 | 작업 | 완료 |
|:---:|------|:---:|
| 1 | 이미지 3장 불러오기 (Ctrl+클릭으로 동시 선택) | ☐ |
| 2 | 장면 순서 확인 (드래그로 조정) | ☐ |
| 3 | AI 자동 생성 시작 | ☐ |

> 자동 생성에는 30~60초 정도 걸려요. 기다리는 동안 다음 단계를 미리 읽어두세요!

|:---:|----------|:----------:|

## 완성 체크리스트

모두 체크되면 제출 완료!

| 항목 | 확인 |
|------|:---:|
| 이미지 3장이 대본 순서대로 배열되어 있다 | ☐ |
| 자막이 모든 장면에 표시된다 | ☐ |
| 자막에 오탈자가 없다 | ☐ |
| BGM이 삽입되고 볼륨이 적당하다 | ☐ |
| 완성 영상을 처음부터 끝까지 재생해서 확인했다 | ☐ |
| 파일명이 `이름_주제.mp4` 형식이다 | ☐ |
