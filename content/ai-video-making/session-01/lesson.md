## 📖 이론 — 생성형 AI와 영상 제작 툴 (20분)

### 생성형 AI란?

==생성형 AI==는 기존 검색과 다르게 **새로운 콘텐츠를 직접 만들어내는** AI다.

| 구분 | 검색 AI | 생성형 AI |
|------|---------|----------|
| 하는 일 | 이미 있는 정보를 찾아줌 | 새로운 글·이미지·영상을 만들어줌 |
| 예시 | 구글 검색, 네이버 검색 | ChatGPT, Gemini, DALL-E |
| 결과물 | 링크·문서 | 텍스트, 이미지, 영상, 음악 |

### 생성형 AI 4분류

| 분류 | 대표 툴 | 만드는 것 |
|:---:|---------|---------|
| 📝 텍스트 | Gemini, ChatGPT, Claude | 글, 대본, 번역, 요약 |
| 🖼️ 이미지 | Midjourney, DALL-E, 미리캔버스 AI | 사진, 일러스트, 썸네일 |
| 🎵 음악 | Suno, Udio | 배경음악, 노래 |
| 🎬 영상 | Veo, Google Flow, CapCut AI | 영상 클립, 숏폼 |

> 💡 오늘은 텍스트·이미지·영상 세 분류를 모두 경험합니다.

### AI 영상 제작 워크플로우

```
기획 (Gemini)  →  이미지 생성 (미리캔버스)  →  영상 편집 (Vrew)  →  완성
  3~5분              5~10분                    15~20분            1편
```

아이디어만 있으면 **30분 안에 영상 1편**이 완성됩니다.

## ✍️ 프롬프트 공식 + AI 윤리 (10분)

### 프롬프트 4요소 공식

==프롬프트==는 AI에게 보내는 **지시문**이다. 4가지 요소를 담으면 훨씬 좋은 결과가 나온다.

| 요소 | 질문 | 예시 |
|:---:|------|------|
| **역할** | AI를 어떤 전문가로 설정할까? | "너는 유튜브 크리에이터야" |
| **맥락** | 상황과 배경을 알려줘 | "중학생 대상 숏폼 영상을 만들 거야" |
| **형식** | 결과물 형태를 지정해 | "장면 5개, 각 20자 이내 자막으로" |
| **조건** | 추가 제약이나 스타일 | "친근한 말투, 이모지 포함" |

#### 나쁜 예 vs 좋은 예

| 나쁜 프롬프트 | 좋은 프롬프트 |
|-------------|-------------|
| "영상 대본 써줘" | "너는 유튜브 크리에이터야. 중학생 대상 '방학 루틴 꿀팁' 숏폼 대본을 장면 5개, 각 20자 이내 자막으로 친근한 말투에 이모지 포함해서 써줘." |
| 결과: 뭘 써야 할지 모름 | 결과: 바로 쓸 수 있는 대본 완성 |

> 💡 **반복 수정이 핵심이다.** 처음 결과가 마음에 안 들면 "더 재밌게", "더 짧게", "3번 장면만 바꿔줘"처럼 계속 다듬으면 된다.

## 🖥️ 강사 라이브 시연 (20분)

### 시연 순서: Gemini → 미리캔버스 → Vrew

> 강사가 직접 예시 주제("우리 학교 급식 Best 3")로 영상을 만드는 과정을 보여줍니다.  
> 학생은 따라하지 않고 **흐름만 파악**하는 시간입니다.

#### 시연 1 — Gemini로 스크립트 만들기

Gemini에 아래 프롬프트를 입력합니다:

```prompt
너는 유튜브 쇼츠 크리에이터야.
주제: 우리 학교 급식 Best 3 소개
대상: 중학생

아래 조건으로 숏폼 영상 자막 대본을 써줘:
- 장면 3개 구성 ([훅] → [Best1] → [Best2+Best3+CTA])
- 각 장면 자막: 20자 이내
- 친근하고 재밌는 말투, 이모지 1개씩 포함
```

> 학생에게 결과를 보여주며: "이게 오늘 여러분이 쓸 대본이에요. 주제만 바꾸면 됩니다."

#### 시연 2 — 미리캔버스로 이미지 3장 만들기

1. miricanvas.com 접속 → 새 디자인 → **9:16 세로형** 선택
2. 좌측 패널 **"AI 이미지 생성"** 클릭
3. 스크립트 장면별 한국어 프롬프트 입력 예시:

```prompt
맛있는 급식 트레이, 귀여운 일러스트 스타일, 밝고 따뜻한 색감, 세로형 구도
```

4. 생성된 이미지 선택 → **다운로드** (PNG, 3장 반복)

#### 시연 3 — Vrew로 영상 완성하기

1. Vrew 실행 → **"이미지로 비디오 만들기"** → 9:16 세로형
2. 이미지 3장 불러오기 → 장면 순서 확인
3. 각 장면에 자막 입력 (Gemini 결과 그대로 붙여넣기)
4. BGM 삽입 → 볼륨 20%
5. **내보내기** → MP4 → 1080×1920

> "이게 전부입니다. 이제 여러분 차례!"

## 🛠️ 직접 실습 (15분)

### 실습 1 — 주제 선정 + 스크립트 (Gemini)

주제를 하나 고르세요. 내가 아는 것, 관심 있는 것이면 뭐든 좋습니다.

| 카테고리 | 예시 주제 |
|---------|-----------|
| 🏫 학교생활 | 급식 Best 3, 시험 기간 공감, 최애 쉬는 시간 |
| 💡 꿀팁 | 공부법 꿀팁, 숙제 빨리 끝내는 법, 유용한 앱 |
| 🎮 관심사 | 요즘 내가 빠진 게임/애니, 취미 소개 |
| 🌟 추천 | 이번 주 읽은 책, 좋아하는 음식 Top 3 |

주제를 정했으면 아래 프롬프트를 ==Gemini==에 붙여넣어 보세요:

```prompt
너는 유튜브 쇼츠 크리에이터야.
주제: [내 주제를 여기에 입력]
대상: [중학생 / 친구들]

아래 조건으로 숏폼 영상 자막 대본을 써줘:
- 장면 3개 구성 ([훅] → [내용1·2] → [마무리+CTA])
- 각 장면 자막: 20자 이내 1~2문장
- 친근하고 재밌는 말투, 이모지 1개씩 포함
```

> 💡 결과가 마음에 안 들면 "더 재밌게 바꿔줘" 또는 "훅 장면만 다시 써줘"로 수정하세요.

### 실습 2 — 이미지 3장 생성 (미리캔버스)

스크립트 각 장면을 이미지로 만듭니다.

**접속:** miricanvas.com → 새 디자인 → ==9:16 세로형== 선택

| 순서 | 방법 |
|:---:|------|
| 1 | 좌측 패널 **"AI 이미지 생성"** 클릭 |
| 2 | 장면 1 내용을 **한국어**로 입력 후 생성 |
| 3 | 마음에 드는 이미지 선택 → **다운로드(PNG)** |
| 4 | 장면 2, 3도 같은 방법으로 반복 |

**이미지 저장 이름:** `scene01.png` `scene02.png` `scene03.png`

> 💡 프롬프트 팁: "귀여운 일러스트 스타일, 밝고 따뜻한 색감, 세로형 구도"를 붙이면 통일감이 생깁니다.

#### 좋은 이미지 고르는 체크리스트

| 항목 | 기준 |
|------|------|
| 세로형(9:16) 구도인가? | 핵심 요소가 화면 중앙에 위치하는지 확인 |
| 장면 내용과 연결되는가? | 이미지만 봐도 내용이 연상되면 합격 |
| 3장 색감이 비슷한가? | 분위기가 통일되면 편집이 훨씬 자연스럽다 |

### 실습 4 — 자막 · AI 목소리 · BGM 추가

## 📦 마무리 — 발표 + 복습 (10분)

### 미니 발표 (5분)

> 자원자 2~3명이 완성한 영상을 보여주고 한 마디씩 합니다.

| 발표 포인트 | 예시 답변 |
|------------|---------|
| 가장 마음에 드는 장면 | "2번 이미지가 너무 귀여웠어요" |
| 어렵거나 아쉬운 점 | "주제 정하는 게 제일 어려웠어요" |
| 다음에 만들고 싶은 것 | "게임 꿀팁 영상 만들어보고 싶어요" |

> ==완성 못 했어도 괜찮아요.== 오늘 배운 파이프라인 흐름이 중요합니다.  
> 집에서 20분이면 충분히 완성할 수 있어요!

---

### 복습 퀴즈 5문항

1. **생성형 AI와 검색 AI의 차이는?**  
   → 검색 AI는 찾아주고, 생성형 AI는 **새로 만들어준다**

2. **오늘 사용한 툴 3종은?**  
   → ==Gemini== (스크립트) · ==미리캔버스== (이미지) · ==Vrew== (영상 편집)

3. **프롬프트 4요소는?**  
   → ==역할== · ==맥락== · ==형식== · ==조건==

4. **AI 윤리 3원칙 중 하나를 말해보세요.**  
   → 얼굴 무단 사용 금지 / 출처 표시 / 허위정보 생성 금지

5. **Google Flow는 오늘 왜 실습을 안 했나요?**  
   → 만 18세 이상·영어·유료 제한이 있어서. **곧 한국어 무료 버전이 열릴 예정!**

---

### 3줄 정리

1. ==생성형 AI==는 텍스트·이미지·영상을 직접 만들어주는 AI다.
2. ==프롬프트 4요소==(역할·맥락·형식·조건)를 담으면 훨씬 좋은 결과가 나온다.
3. ==Gemini → 미리캔버스 → Vrew== 파이프라인으로 카메라 없이 영상 1편을 완성할 수 있다.

> **"AI는 도구다. 오늘 그 도구를 처음 쥔 여러분이 이미 크리에이터다."** 🎬

## 📋 프롬프트 템플릿 모음

### 🚀 템플릿 1 — 영상 주제 추천 프롬프트

```prompt
나는 [관심사/취미]에 관심 있는 [중학생]이야.
유튜브 쇼츠·인스타 릴스용 숏폼 영상 주제를 10개 추천해줘.

조건:
- 30~60초 안에 완성할 수 있는 주제
- 촬영 없이 AI 생성 이미지로만 만들 수 있는 내용
- 요즘 10~20대가 관심 가질 만한 것 위주로
- 주제마다 한 줄 설명 + 예상 훅 문장도 붙여줘
```

---

### 🤖 템플릿 2 — 숏폼 자막 대본 생성 프롬프트

```prompt
너는 유튜브 쇼츠 전문 크리에이터야.
주제: [내 주제]
대상: [중학생 / 친구들]

아래 구조로 30~60초 분량의 숏폼 자막 대본을 써줘:
- [훅]: 시청자를 멈추게 하는 첫 문장
- [내용1]: 핵심 포인트 첫 번째 (20자 이내)
- [내용2]: 핵심 포인트 두 번째 (20자 이내)
- [CTA]: 팔로우·댓글 유도 문장

말투는 [친근하고 재밌는] 구어체로, 이모지 1개씩 포함해줘.
```

### 🎨 템플릿 3 — 미리캔버스 AI 이미지 프롬프트

주제에 따라 아래 패턴으로 입력하세요:

```prompt
[장면 내용]을 나타내는 장면,
귀여운 일러스트 스타일, 밝고 따뜻한 색감,
세로형(9:16) 구도, 화면 중앙에 주인공 배치
```

### 📣 템플릿 4 — 인스타 캡션 + 해시태그 생성

```prompt
내가 만든 숏폼 영상 주제는 "[주제]"야.
대상: 중학생·10대
영상 내용 요약: [한 줄 요약]

아래 조건으로 인스타그램 릴스용 캡션을 써줘:
- 첫 줄: 시선을 끄는 강렬한 문장 (이모지 포함)
- 중간: 영상 내용 1~2줄 소개
- 마지막: 저장·팔로우·댓글 유도 CTA
- 해시태그: 10~15개 (국문·영문 혼합)
```
