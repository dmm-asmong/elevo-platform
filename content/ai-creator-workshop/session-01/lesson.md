# AI 3종 세트로 첫 숏폼 완성하기 🎬

> **"촬영 없이, 편집 경험 없이, AI 3종 세트로 첫 숏폼을 완성한다"**  
> ==ChatGPT==로 대본을 쓰고, ==DALL-E==로 이미지를 만들고, ==Vrew==로 편집을 완성하는 풀 파이프라인을 90분 안에 경험한다.

---

## 📋 [강사용] 운영 가이드

> **이 섹션은 강사 전용입니다. 수강생 화면 공유 시 이 섹션은 넘어가세요.**

### 시간 배분표

| 단계 | 시간 | 파트 | 핵심 활동 |
|------|------|------|-----------|
| 오프닝 | 0~5분 | 🎯 완성본 먼저 보기 | 강사 제작 예시 영상 재생 |
| Step 1 | 5~25분 | 🤖 AI로 기획하기 | 개인 주제 선택 → ChatGPT 대본 → 이미지 프롬프트 변환 |
| Step 2 | 25~40분 | 🎨 DALL-E로 이미지 만들기 | 장면별 5개 이미지 생성 → 저장 |
| Step 3 | 40~75분 | ✂️ Vrew로 완성하기 | 조립 → 자막 → BGM → 전환 → 9:16 export |
| 마무리 | 75~90분 | 📦 공유 + 챙겨가기 | 미니 발표 + 템플릿 저장 + 다음 아이디어 |

### 리스크 대응

| 상황 | 대응 방법 |
|------|-----------|
| 이미지 생성이 느릴 때 | 강사 백업 이미지 5장을 카카오톡/구글드라이브로 즉시 공유 |
| Vrew 미설치 수강생 | 모바일 Vrew 앱으로 진행하거나 옆 사람과 페어 작업 유도 |
| 주제를 못 정할 때 | 강사 예시 주제("요즘 학생들 공부법 꿀팁 TOP 3") 제공 및 바로 따라하기 |
| 완성이 늦는 수강생 | 완성된 수강생이 자연스럽게 옆 사람을 도와주도록 유도 |
| ChatGPT 유료 기능 필요 시 | Gemini(gemini.google.com) 무료 버전 대안 사용 |

### 강사 사전 준비사항

- [ ] Vrew 최신 버전 설치 확인 (vrew.ai)
- [ ] ChatGPT 접속 상태 사전 점검

## 🎯 완성본 먼저 보기 (5분)

> 강사가 미리 만든 **"요즘 학생들 공부법 꿀팁 TOP 3"** 쇼츠 영상을 재생합니다.

강사 예시 영상 스펙:

| 항목 | 내용 |
|------|------|
| 제목 | 요즘 학생들 공부법 꿀팁 TOP 3 |
| 길이 | 33초 |
| 제작 시간 | 33분 (대본 3분 + 이미지 5분 + Vrew 조립 25분) |
| 사용 도구 | ChatGPT + DALL-E + Vrew |

영상 재생 후, 수강생에게 질문합니다:

> "이 영상 만드는 데 얼마나 걸렸을 것 같아요?"

잠깐 답변을 받은 뒤 공개합니다:

> **대본 3분 + 이미지 5분 + Vrew 편집 25분 = 총 33분.**  
> 오늘 90분 안에 여러분도 이 영상을 직접 만들어 가져갑니다! 🚀

### 오늘의 AI 파이프라인

| 단계 | 도구 | 역할 | 결과물 |
|:---:|---|---|---|
| **1️⃣ 기획** | ChatGPT | 주제 선정 → 60초 대본 생성 → 이미지 프롬프트 추출 | 대본 + 프롬프트 5개 |
| **2️⃣ 시각화** | DALL-E (ChatGPT 내 이미지 탭) | 장면별 9:16 이미지 생성 | 이미지 5장 |
| **3️⃣ 편집** | Vrew | 이미지 조립 → 자막 → BGM → 전환 → export | 완성 숏폼 영상 1편 |

> 💡 세 도구 모두 **계정만 있으면 무료**로 시작할 수 있다. 별도 앱 설치는 Vrew만!

## 🤖 Step 1 — AI로 기획하기 (20분)

### 2-1. 주제 선택하기 (5분)

==숏폼==에서 가장 좋은 주제는 **이미 내가 아는 것**이다. 아래 4가지 카테고리 중 하나를 골라보자.

| 카테고리 | 예시 주제 |
|---------|-----------|
| 🤝 공감형 | 학생 일상, 시험 기간 공감, 방학 루틴, 급식 현실 |
| 💡 정보형 | 꿀팁 3가지, 유용한 앱·도구 추천, 공부법 비교 |
| 🌸 감성형 | 여행 브이로그, 취미 소개, 음식 먹방 감성 |
| 🔥 트렌드형 | AI 도구 소개, 요즘 챌린지, 신상 리뷰 |

> 💡 완벽한 주제를 고를 필요 없다. **일단 하나 고르고 시작**하자.

#### 예시 주제 → 훅 문장 완성형

| 주제 | 훅 문장 예시 |
|------|------------|
| 공부법 꿀팁 | "시험 3일 전에도 A+ 받는 방법 알아? 비밀 공개할게." |
| 시험 기간 공감 | "시험 기간에 이 중 하나라도 해봤으면 공감해줘." |
| 유용한 앱 추천 | "이 앱 아직도 모르면 진짜 손해야. 무료인데 미쳤음." |
| 방학 루틴 | "방학 때 이거 한 사람 vs 안 한 사람, 차이 실화임?" |

### 2-2. ChatGPT 대본 생성하기 (10분)

아래 프롬프트를 복사해서 ChatGPT에 **그대로 붙여넣어** 보자.

```prompt
너는 유튜브 쇼츠·릴스·틱톡 전문 크리에이터야.

내 주제는 [나의 주제]야.
시청 대상: [10~20대 학생]

아래 조건에 맞게 숏폼 대본을 작성해줘:
- 총 길이: 30~60초 분량 (장면 5개)
- 구성: [훅] → [내용1] → [내용2] → [내용3] → [CTA]
- 각 장면 자막: 20자 이내 1문장
- 말투: 친근하고 자연스러운 구어체
- 이모지 각 장면에 1개 포함
- 각 파트를 [훅], [내용1], [내용2], [내용3], [CTA] 태그로 구분해서 출력해줘
```

#### 대본 예시 결과 (공부법 꿀팁 주제)

```
[훅] 시험 3일 전에도 A+ 받는 방법 알아? 📖
[내용1] 교과서 말고 기출문제부터 봐. 패턴이 보여 👀
[내용2] 요약 노트 대신 핵심 키워드를 소리 내서 읽어 🔊
[내용3] 공부 30분 → 5분 쉬기 무조건 지켜. 집중력 2배야 ⏱️
[CTA] 써봤으면 댓글에 알려줘! 팔로우하면 다음 꿀팁 알림 옴 🔔
```

> 장면 번호를 붙이는 이유: 나중에 Vrew에서 **장면 순서대로 이미지를 배치**하기 때문입니다.

#### 수정이 필요할 때 — 수정 프롬프트

결과가 마음에 들지 않을 때 아래를 그대로 입력하세요.

**특정 장면을 바꾸고 싶을 때:**

```prompt
3번 장면을 더 공감되고 재밌게, 20자 이내로 바꿔줘.
```

**전체 톤을 바꾸고 싶을 때:**

```prompt
전체 말투를 더 MZ 감성으로 바꾸고 이모지를 더 재밌는 걸로 교체해줘.
```

> ==완벽한 대본을 만들 필요 없어요.== Vrew에서 언제든 자막을 수정할 수 있습니다.

### 2-3. 이미지 프롬프트 변환하기 (5분)

대본이 완성되면 이 프롬프트로 DALL-E용 영어 프롬프트를 뽑아낸다.

```prompt
위 대본의 각 장면([훅], [내용1], [내용2], [내용3], [CTA])을 DALL-E로 생성할 수 있는
영어 이미지 프롬프트 5개로 변환해줘.

조건:
- 각 프롬프트는 20~30단어 이내
- 세로형 숏폼(9:16 vertical)에 어울리는 장면 구도
- 스타일: bright Pixar illustration style 또는 cute cartoon style
- 인물이 등장할 경우 표정과 감정 묘사 포함
- 장면 번호([훅], [내용1] 등) 태그를 앞에 붙여서 출력해줘
```

#### 변환 결과 예시 (공부법 꿀팁 기준)

| 장면 | 자막 | DALL-E 영어 프롬프트 |
|:---:|------|---------------------|
| 훅 | 시험 3일 전에도 A+ 받는 방법 알아? 📖 | Cute student looking at calendar with "3 days left" circled, excited and determined expression, bright study room, vertical 9:16, Pixar illustration style |
| 내용1 | 교과서 말고 기출문제부터 봐 👀 | A student highlighting past exam papers on a clean desk, focused expression, top-down shot, warm tones, vertical 9:16, bright cartoon style |
| 내용2 | 핵심 키워드를 소리 내서 읽어 🔊 | A cheerful student reading aloud from a notebook, speech bubbles with keywords floating, colorful pastel background, vertical 9:16, Pixar style |
| 내용3 | 공부 30분 → 5분 쉬기 무조건 ⏱️ | Split scene: student studying at desk and then stretching happily, timer showing 30 minutes, soft illustration style, vertical 9:16 |
| CTA | 써봤으면 댓글에 알려줘! 🔔 | Cute student waving at camera with thumbs up, comment bubble icons around, bright energetic background, vertical 9:16, Pixar cartoon style |

## 🎨 Step 2 — DALL-E로 이미지 만들기 (15분)

### ChatGPT 내 이미지 탭 사용하기

==DALL-E는 ChatGPT 안에 이미 들어있다. 별도 가입·설치 불필요!==

대화창 하단의 **카메라(이미지) 아이콘**을 클릭하면 바로 이미지 생성 모드로 전환된다.

#### 4단계 사용 흐름

**1️⃣ ChatGPT 열기**
- 기존 대본 대화창에서 이어서 진행
- 하단 **이미지 아이콘(카메라 버튼)** 클릭

**2️⃣ 프롬프트 붙여넣기**
- 2-3에서 변환한 영어 프롬프트를 장면별로 하나씩 입력
- `Generate` 실행

**3️⃣ 이미지 선택**
- 생성된 이미지 중 가장 마음에 드는 것 선택
- 마음에 들지 않으면 "좀 더 귀엽게 해줘" 또는 "배경을 밝게 해줘"로 재생성

**4️⃣ 저장**
- 이미지 오른쪽 클릭 → **"다른 이름으로 저장"**
- 바탕화면에 `내쇼츠` 폴더 만들기
- 파일명: `scene01.png` ~ `scene05.png` 순서대로 저장

> 💡 파일명을 미리 정리하면 Vrew에서 불러올 때 헷갈리지 않아요!

#### 좋은 이미지 고르는 팁

| 체크 항목 | 기준 |
|----------|------|
| 피사체가 선명한가? | 주인공이 흐리거나 이상하게 변형되지 않았는지 확인 |
| 세로형(9:16)에 어울리는가? | 세로 중심 구도인지, 핵심 요소가 잘 보이는지 확인 |
| 대본 내용과 연결되는가? | 이미지만 봐도 "어떤 내용인지" 느껴지면 합격 |
| 5장 색감이 통일되어 있는가? | 이미지들의 전체 분위기가 비슷하면 편집이 훨씬 자연스럽다 |

> ⚠️ **저작권 안내:** DALL-E로 생성된 이미지는 AI가 직접 만든 콘텐츠로 타인의 저작물을 직접 복제하지 않습니다. 단, 상업적 사용 전에는 OpenAI 이용 약관을 반드시 확인하세요.

## ✂️ Step 3 — Vrew로 완성하기 (35분)

### Vrew란?

==Vrew==는 이미지와 자막만 있으면 자동으로 세로형 영상을 만들어주는 **무료 편집 프로그램**이다.  
자막 입력, BGM 삽입, 화면 전환까지 클릭 몇 번으로 완성된다.

| 항목 | 내용 |
|------|------|
| 다운로드 | [vrew.ai](https://vrew.ai) → 무료 다운로드 |
| 운영체제 | Windows / Mac / 모바일 앱 지원 |
| 가격 | **무료** (워터마크 없이 내보내기 가능) |

---

### 1️⃣ 새 프로젝트 → 9:16 세로형

1. Vrew 실행 → 상단 **"새로 만들기"** 클릭
2. **"이미지로 비디오 만들기"** 선택
3. 화면 비율: ==**9:16 (세로형)**== 선택 → 확인

> "16:9 아닌가요?" 라는 질문이 나오면: 릴스·틱톡·쇼츠는 모두 **세로 영상**입니다. 9:16이 맞습니다!

---

### 2️⃣ 이미지 5장 불러오기

1. 화면 왼쪽 **"클립 추가"** 버튼 클릭
2. 바탕화면 `내쇼츠` 폴더에서 `scene01.png` ~ `scene05.png` 선택
3. ==**Ctrl 키를 누른 채로 5장 동시 선택**== → 열기
4. 장면 순서 확인 (드래그로 조정 가능)

| 체크 포인트 | 확인 |
|------------|:----:|
| 이미지 5장 모두 불러왔는가? | ☐ |
| 순서가 장면 1~5 순서인가? | ☐ |
| 9:16 세로 비율로 잘 들어왔는가? | ☐ |

---

### 3️⃣ 자막 입력하기

1. 타임라인에서 **첫 번째 클립** 클릭
2. 오른쪽 패널 **"자막"** 탭 클릭
3. ChatGPT에서 생성한 **[장면 1]** 문구 입력
4. 장면별로 반복 (총 5회)

| 장면 | 자막 예시 | 권장 표시 시간 |
|:---:|---------|:-----------:|
| 장면 1 (훅) | 시험 3일 전에도 A+ 받는 방법 알아? 📖 | 6~7초 |
| 장면 2 (내용1) | 교과서 말고 기출문제부터 봐 👀 | 6~7초 |
| 장면 3 (내용2) | 핵심 키워드를 소리 내서 읽어 🔊 | 6~7초 |
| 장면 4 (내용3) | 공부 30분 → 5분 쉬기 무조건 ⏱️ | 6~7초 |
| 장면 5 (CTA) | 써봤으면 댓글에 알려줘! 팔로우 ❤️ | 7~8초 |

> ==자막 폰트 추천: 나눔스퀘어 Bold 또는 Pretendard==  
> 자막 색: **흰색 + 검정 테두리** (어떤 배경에서도 선명하게 보임)

---

### 4️⃣ BGM 추가하기

**방법 A: Vrew 내장 무료 음악 (초보자 권장)**

1. 상단 메뉴 **"삽입"** → **"배경음악"** → **"Vrew 음악 라이브러리"**
2. 장르: **Bright / Pop / Acoustic** 카테고리 추천
3. 미리 듣기 후 마음에 드는 트랙 선택 → **삽입**
4. 볼륨: ==**20~30%**== (자막을 방해하지 않는 수준)

**방법 B: Suno AI로 음악 직접 만들기 (선택사항)**

접속: **suno.com** → 구글 계정으로 무료 로그인

```prompt
bright and energetic background music for student tips short video,
upbeat pop style, no lyrics, 40-60 seconds, light and motivating mood
```

> 💡 Suno로 생성한 음악을 MP3로 다운로드 → Vrew에서 "PC에서 불러오기"로 삽입

---

### 5️⃣ 전환 효과 설정하기

1. 타임라인에서 클립과 클립 사이 **"+"** 버튼 클릭
2. **"전환 효과"** → ==**Fade**== 또는 **Dissolve** 선택
3. 전환 시간: ==**0.5초**==

> 화려한 효과는 오히려 집중을 방해합니다. ==단순한 Fade가 가장 세련되고 프로답습니다.==

### 6️⃣ 1080×1920 MP4 내보내기

2. 형식: **MP4**

4. 품질: **고화질**

### 📋 프롬프트 템플릿 모음 4종

강의 이후 **혼자 숏폼을 제작할 때 바로 복붙**해서 쓸 수 있는 템플릿 모음입니다.  
`[대괄호]` 안의 내용만 바꿔서 사용하세요.

---

#### 🚀 템플릿 1 — 숏폼 주제 추천 프롬프트

주제가 막막할 때 AI에게 먼저 물어보자.

```prompt
나는 [관심사/취미/전공]에 관심 있는 [나이대] 학생이야.
유튜브 쇼츠·인스타 릴스용 숏폼 영상 주제를 10개 추천해줘.

조건:
- 30~60초 안에 완성할 수 있는 주제
- 촬영 없이 AI 생성 이미지로만 만들 수 있는 내용
- 요즘 트렌디하고 10~20대가 관심 가질 만한 것 위주로
- 주제마다 한 줄 설명 + 예상 훅 문장도 붙여줘
```

---

#### 🤖 템플릿 2 — 30~60초 숏폼 대본 생성 프롬프트

주제가 정해졌다면 대본을 바로 뽑아보자.

```prompt
너는 유튜브 쇼츠 전문 크리에이터야.
주제: [나의 주제]
타겟: [타겟 시청자 — 예: 10~20대 학생]

아래 구조로 30~60초 분량의 숏폼 대본을 작성해줘:
- [훅]: 시청자를 멈추게 하는 첫 1~2문장 (질문형 또는 놀라운 사실)
- [내용1]: 핵심 포인트 첫 번째 (20자 이내)
- [내용2]: 핵심 포인트 두 번째 (20자 이내)
- [내용3]: 핵심 포인트 세 번째 (20자 이내)
- [CTA]: 팔로우·좋아요·댓글 유도 문장

말투는 [친근한/유머러스한/전문적인] 구어체로 써줘.
각 장면에 이모지 1개씩 포함해줘.
```

---

#### 🎨 템플릿 3 — DALL-E 이미지 생성용 영어 프롬프트 변환

대본을 DALL-E에 바로 쓸 수 있는 영어 프롬프트로 변환한다.

```prompt
위 대본의 각 파트([훅], [내용1], [내용2], [내용3], [CTA])를
DALL-E로 이미지를 생성할 수 있는 영어 프롬프트 5개로 변환해줘.

조건:
- 각 프롬프트는 20~30단어 이내
- 세로형 숏폼(9:16 vertical)에 어울리는 장면 구도
- 스타일: [bright Pixar illustration / cute cartoon / realistic photo] 중 선택
- 인물 등장 시 표정과 감정을 구체적으로 묘사
- 장면 태그([훅], [내용1] 등)를 앞에 붙여서 출력해줘
```

---

#### 📣 템플릿 4 — 인스타 캡션 + 해시태그 생성 프롬프트

업로드 직전 캡션까지 AI로 완성하자.

```prompt
내가 만든 숏폼 영상 주제는 "[주제]"야.
대상: [타겟 시청자]
영상 내용 요약: [한 줄 요약]

아래 조건으로 인스타그램 릴스용 캡션을 작성해줘:
- 첫 줄: 시선을 끄는 강렬한 문장 (이모지 포함)
- 중간: 영상 내용 1~2줄 소개
- 마지막: 저장·팔로우·댓글 유도 CTA
- 해시태그: 10~15개 (국문·영문 혼합)
- 전체 말투: 친근하고 가볍게
```
