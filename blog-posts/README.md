# Blog Posts 폴더 📝

앞으로 작성하는 **모든 네이버 블로그 포스팅 초안**을 이 폴더에 저장합니다.

## 파일 이름 규칙
```
YYYY-MM-DD_포스팅-제목-요약.md
```

## 파일 내부 메타 형식
각 파일 상단에 아래 항목을 포함합니다.
- **작성일**
- **카테고리** (강사스토리 / AI교육 / 온라인활용 등)
- **핵심 키워드** (네이버 SEO용 해시태그)
- **상태**: 초안 작성 중 / 발행 가능 ✅ / 발행 완료 🚀
