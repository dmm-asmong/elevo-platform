## 1. 디자인 리팩토링

### 배경

초기 "Hyper-Saturated Fluid" 디자인 시스템(노란 배경 히어로, 큰 border-radius)이 전체적으로 어색하고, Yellow(`#FDE047`)가 15개 이상 요소에 동시 적용되어 강조 포인트가 사라진 상태였다.

### 방향 전환: "Technical Editorial"

- **컨셉:** Vercel·Linear 수준의 정제된 다크 에디토리얼. 컬러가 아닌 타이포그래피와 공간으로 위계를 잡는다.
- **Yellow 규칙:** 페이지당 최대 3곳 (사이드바 상단 2px 선 / 히어로 "순간" 단어 / 활성 nav 인디케이터 점)

### 주요 변경 내용

#### `globals.css`
- 배경색: `#0A0A0A` → `#080808` (더 깊은 검정)
- 중간 surface 단계 재정의: `#111111`(카드), `#181818`(elevated)
- `prose-dark` strong 색상: Yellow → `#f0f0f0` (prose 내 yellow 홍수 차단)
- `prose-dark` h3 색상: Yellow → `#d0d0d0`
- blockquote 테두리: Yellow → `#333` 단색
- `@keyframes pulse-dot` 추가 (히어로 레이블 점 애니메이션)

#### 히어로 섹션 (`app/page.tsx`)
- 노란 배경 + `borderRadius: "0 0 80px 80px"` → 완전 제거
- 다크 배경 위 `border-bottom: 1px solid #1a1a1a` 구분선으로 대체
- 스탯 뱃지 3개(완성커리큘럼·코딩경력필요·분/회차) 제거
- 점 패턴 텍스처 간격: 28px → 14px (후에 아예 제거)
- 헤드라인 "순간" 만 Yellow 유지

#### 섹션 구분
- `운영 중` / `준비 중` 섹션에 모노스페이스 번호(`01`, `02`) + 세로 구분선 추가
- 준비 중 카드는 전체적으로 어둡게 처리하여 시각적 비활성 명확화

#### `CourseCard.tsx`
- border-radius: `rounded-[28px]` → `rounded-2xl` (16px) — 에디토리얼 톤에 적합
- 노란 full border 제거, 대신 hover 시 `border-color: #2a2a2a` + `translateY(-1px)` 효과
- 회차 뱃지: Yellow fill → Yellow tint outline (`rgba(253,224,71,0.1)`, border)
- 태그 영역 간소화: 최대 3개, 더 작은 크기

#### `SideNav.tsx`
- 상단 2px Yellow 선 = 유일한 브랜드 컬러 마커로 집약
- 섹션 레이블: 더 작고 흐리게 (`tracking-[0.18em]`)
- border: `#1c1c1c` → `#161616` (더 얇게)

### 텍스트 가독성 개선 (3라운드)

다크 배경에 어두운 회색 텍스트가 묻히는 문제를 3차례 반복 개선.

| 이전 값 | 이후 값 | 적용 위치 |
|---------|---------|-----------|
| `#404040` | `#888` | 브레드크럼, 회차 번호, 이전/다음 라벨 |
| `#525252` | `#999` | 소요시간, 툴명, 탭 비활성 텍스트 |
| `#737373` | `#aaa` | 이전/다음 세션 제목 |

| `#505050` | `#888` | 카드 설명 텍스트 |

## 3. PDF 슬라이드 지원 추가

### 배경

기존 프레젠테이션 모드는 `public/slides/[courseSlug]/[sessionId].html`만 지원했다. 완성된 HTML 슬라이드가 없는 회차에서 PDF를 활용할 수 있도록 확장 필요.

### 구현 방식

브라우저 네이티브 PDF 렌더링을 활용. `<iframe src="[pdf경로]">`로 별도 라이브러리 없이 작동.

**적용 파일:**

```
public/slides/vibe-coding/session-01.pdf  ← Hello_Vibe_Coding.pdf 복사
```

**`lib/content.ts` 수정:**

```typescript
// HTML과 PDF 모두 감지
const htmlExists = fs.existsSync(path.join(publicSlideDir, `${sessionId}.html`))
  || fs.existsSync(path.join(sessionDir, "slide.html"));
const pdfExists = fs.existsSync(path.join(publicSlideDir, `${sessionId}.pdf`));

// HTML 우선, 없으면 PDF
const slideUrl = htmlExists
  ? `/slides/${courseSlug}/${sessionId}.html`
  : pdfExists
  ? `/slides/${courseSlug}/${sessionId}.pdf`
  : null;
```

**`SessionContent` 인터페이스에 `slideUrl: string | null` 추가**

**`present/page.tsx` 수정:**
- `content.hasSlideHtml` → `content.slideUrl` 체크로 변경
- URL을 동적으로 전달

### 향후 추가 방법

다른 회차 PDF는 `session-02.pdf`, `session-03.pdf` 이름으로 동일 폴더에 넣으면 자동으로 프레젠테이션 버튼이 표시됨.

## 4. 수강생용 교안(lesson.md) 시스템 구축

### 배경

`slide-outline.md`는 강사 멘트·유의사항이 혼재된 강사 전용 문서였다. 수강생이 플랫폼에서 직접 열람할 수 있는 **학습 자료 탭**이 필요했다.

### 콘텐츠 스타일 규칙 확립

1회차를 기준으로 수강생 대상 `lesson.md` 작성 규칙을 확립했다.

| 요소 | 규칙 |
|------|------|
| h2 섹션 | 이모지 포함 (예: `## 🤖 바이브 코딩이란?`) |
| h3 소주제 | 이모지 없이 소제목만 |
| 골드 강조 | `==text==` → `#FDE047` 색상 |
| 블루 강조 | `!!text!!` → `#60a5fa` 색상 |
| 프롬프트 예시 | ` ```prompt ` 블록 (일반 코드 블록 금지) |
| 용어 정리 | `### 📖 용어 정리` + 표(용어 \| 쉬운 풀이) |
| 핵심 정리 | `## ✅ 오늘의 핵심 정리` + 번호 목록 |
| 다음 예고 | `## ➡️ 다음 시간 예고` + 과제 |

### MarkdownViewer 기능 확장 (`components/viewer/MarkdownViewer.tsx`)

| 추가 기능 | 구현 방식 |
|-----------|-----------|
| 파이프 테이블 파싱 | 정규식으로 `\| header \|` 블록 감지 후 `<table>` 변환 |
| 헤딩 앵커 ID | `slugifyHeading()` 함수로 모든 h1~h4에 `id` 속성 자동 부여 |
| `==text==` 골드 강조 | `<mark class="hl-gold">` 변환 |
| `!!text!!` 블루 강조 | `<mark class="hl-blue">` 변환 |
| ` ```prompt ` 블록 | `<div class="prompt-block">` + 레이블 "프롬프트 예시" 렌더링 |

### Sticky TOC 사이드바 구현

기존 인라인 TOC(콘텐츠 상단 삽입) → 스크롤 추적 사이드바로 전환.

**신규 파일:**

- `lib/toc.ts` — `slugifyHeading()` + `extractTOC()` (서버·클라이언트 공유 유틸)
- `components/viewer/StickyTOC.tsx` — 스크롤 기반 active 추적 사이드 TOC

**`page.tsx` 레이아웃 변경:**

```
기존: max-w-3xl 단일 컬럼
이후: max-w-1280px, flex row → [콘텐츠 카드 flex-1] + [StickyTOC w-200px sticky top-24px]
```

**TOC 싱크 방식:**

`IntersectionObserver`(불안정) → `scroll` 이벤트 + `getBoundingClientRect().top ≤ 120px` 조건으로 교체. 스크롤 위치에서 마지막으로 통과한 h2를 active로 설정.

### 슬라이드 구성안 탭 제거

수강생 대상 플랫폼에서 불필요한 강사용 탭 제거. `page.tsx`의 `tabs` 배열에서 `slide-outline` 항목 삭제.

### h2·h3 가독성 개선 (`globals.css`)

| 요소 | 변경 내용 |
|------|-----------|
| h2 | `margin-top: 3rem`, `border-bottom: 1px solid #242424` |
| h3 | 골드 왼쪽 선(`border-left: 2px solid rgba(253,224,71,0.5)`) + 미세 배경(`rgba(255,255,255,0.03)`) + border-radius |
| h4 | monospace 폰트, uppercase, muted 컬러 |
| 모든 헤딩 | `scroll-margin-top: 96px` (TOC 앵커 이동 시 헤딩 가림 방지) |

### 배경 서페이스 레벨업 (옵션 A 선택)

어두운 배경으로 인한 가독성 저하 문제를 서페이스 전반적으로 올려서 해결.

| 항목 | 이전 | 이후 |
|------|------|------|
| body 배경 | `#080808` | `#0d0d0d` |
| 콘텐츠 카드 | `#0f0f0f` | `#181818` |
| prose 본문 텍스트 | `#a0a0a0` | `#bcbcbc` |
| 인라인 코드 배경 | `#161616` | `#1e1e1e` |
| 코드 블록 배경 | `#101010` | `#161616` |
| 테이블 헤더 배경 | `#111` | `#1c1c1c` |
| 테이블 셀 텍스트 | `#a0a0a0` | `#b8b8b8` |

### 2~7회차 lesson.md 일괄 생성

6개 에이전트를 병렬로 디스패치해서 2~7회차 `lesson.md`를 동시에 생성.

- 각 에이전트: `slide-outline.md` 읽기 → 강사 전용 내용 제거 → 확립된 스타일 규칙 적용 → `lesson.md` 저장 → `meta.json` `hasLesson: true` 업데이트
- 총 소요시간: ~135초 (병렬 처리)

## 5. 기술 이슈 & 해결

### Next.js 설정 관련

- **`next.config.ts` 미지원:** Next.js 14에서 `.ts` 설정 파일 미지원 → `.mjs`로 변경
- **CSS side-effect import 에러:** `declarations.d.ts` 에 `declare module "*.css"` 추가로 해결

### 개발 서버 포트 충돌

여러 세션에서 서버를 시작하면서 3000 → 3001 → 3002 → 3003으로 포트가 밀리는 현상 발생.

```powershell
# 해결: PowerShell로 점유 프로세스 일괄 종료
Stop-Process -Id 46776,7916,22824,42608 -Force
```

이후 3000 포트에서 정상 시작.

### gws CLI 경로 제한

`gws drive files export`의 `--output` 경로가 현재 디렉토리 기준 상대 경로만 허용. 절대 경로 입력 시 "outside the current directory" 에러 발생.

**해결:** `cd elevo-platform` 이후 상대 경로로 export.

## 7. UI/UX 고도화 및 플랫폼 안정화 (2026-03-31 야간)

### 디자인 컨셉: "Edgy & Premium Dark"

단순한 다크 모드를 넘어, 고해상도의 미학과 사용자 경험을 극대화하기 위해 디자인 시스템을 한 단계 더 격상시켰다.

- **핵심 키워드**: 깊이감(Depth), 대기광(Atmospheric Glow), 글래스모피즘(Glassmorphism), 타이포그래피 조화(Harmonious Typography).
- **배경 시스템**: 단순 검정 (`#0A0A0A`)에서 깊은 차콜/네이비(` #0a0a0c`)로 변경하고, 화면 가장자리에 은은한 블루/옐로우 방사형 그라데이션을 배치하여 공간감을 부여.
- **노이즈 텍스처**: `mix-blend-soft-light`가 적용된 미세한 스타더스트 패턴을 레이어링하여 디지털 질감을 강화.

### 주요 작업 내용

#### 히어로 섹션 고도화 (`app/page.tsx`)
- **AI 비주얼 생성**: `generate_image` 스킬을 활용하여 플랫폼의 아이덴티티를 담은 **Premium 3D Abstract Visual** 생성 및 배경 통합.
- **타이포그래피 리밸런싱**: "Elevating Your GenAI" 헤드라인의 크기를 `4.5rem`으로 최적화하고, 이탤릭체와 투명도를 교차 사용하여 에디토리얼한 감각 부여.
- **접근성 최적화**: 히어로 섹션의 높이를 축소하여 첫 화면에서 하단 커리큘럼 카드가 자연스럽게 노출되도록 조정.

#### 사이드바 디자인 업그레이드 (`SideNav.tsx`)
- **글래스모피즘**: `backdrop-filter: blur(20px)`와 미세한 흰색 테두리(`border-white/5`)를 적용하여 배경 위에 유리판이 떠 있는 듯한 입체감 구현.
- **인터랙티브 메뉴**: 활성 메뉴에 Yellow Glow 도트 인디케이터와 부드러운 배경 강조 효과 추가.

#### 커리큘럼 상세 페이지 리뉴얼 (`[courseSlug]/page.tsx`)
- **레이아웃 안정화**: 사이드바 너비(`280px`)와 메인 콘텐츠 여백을 동기화하여 화면 겹침 현상 해결.
- **회차 카드 디자인**: 글래스모피즘 스타일의 세션 카드로 변경하고, 마우스 호버 시 내부 광색(Inner Glow)이 퍼지는 인터랙션 추가.

### 기술 이슈 해결

| 문제점 | 원인 | 해결 방법 |
|--------|------|-----------|
| **커리큘럼 페이지 에러** | Next.js 14.2 환경에서 `params` 비동기 처리 미흡 | `await params` 구문을 보강하여 런타임 안정성 확보 |
| **`addListener` 런타임 에러** | 빌드 캐시 충돌 및 구형 API 참조 | `.next` 폴더 강제 삭제 후 서버 재시작으로 해결 |
| **포트 점유 문제** | 이전 프로세스 미종료 | 점유 포트(`3000`, `3001` 등) 확인 후 `3002`번에서 안정적 시작 |
