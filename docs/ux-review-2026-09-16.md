# ELEVO 플랫폼 UX/UI 리뷰 (2026-09-16)

사용자 관점 + UX/UI 전문가 관점으로 사이트 전체(홈, 강의 목록, 강의 상세, 세션 상세, 스킬 라이브러리, 전역 스타일)를 코드 레벨로 검토한 결과. 심각도 순으로 정리했으며, 각 항목에 근거 파일 경로를 남겨 추후 수정 작업 시 그대로 참고할 수 있게 했다.

아직 어떤 항목을 고칠지는 정하지 않은 **리뷰 기록**이다. 실제 수정은 우선순위를 정한 뒤 별도로 진행한다.

---

## 🔴 실질적 결함 (바로 손봐야 함)

1. **홈 히어로의 "Start Training" 버튼이 아무 동작도 안 함**
   `app/page.tsx:44` — `href`도 `onClick`도 없는 장식용 `<button>`. 방문자가 사이트에서 제일 먼저 누르는 CTA가 죽어있는 셈.

2. **히어로의 "7 Sessions" 배지가 하드코딩**
   `app/page.tsx:47-49` — 지금은 강의가 7회/7회/1회 등 제각각인데 이 숫자는 강의가 하나뿐이던 시절의 잔재로 보임. 오해 소지 있음.

3. **키보드 포커스 스타일이 코드 전체에 전무**
   `:focus`/`focus-visible`/`outline` 커스터마이징이 `app/globals.css`를 포함해 프로젝트 전체에 한 군데도 없음(grep 결과 0건). Tab 키로 이동하는 사용자와 접근성 심사에 취약.

4. **404/에러 페이지가 ELEVO 디자인과 완전히 동떨어짐**
   `app/not-found.tsx`, `app/error.tsx`가 존재하지 않음. 존재하지 않는 강의/세션 URL로 들어오면(`notFound()` 호출 지점: `app/courses/[courseSlug]/page.tsx:16`, `app/courses/[courseSlug]/[sessionId]/page.tsx:16,20`, `app/library/skills/[skillSlug]/page.tsx:15`) Next.js 기본 흰 화면이 뜸. 사이드바·폰트·톤 전부 깨짐.

5. **학습 진행 상황(수강 완료)을 전혀 기억하지 못함**
   "3 / 7" 표시(`app/courses/[courseSlug]/[sessionId]/page.tsx:87-89, 130-138`)는 세션 배열의 고정 위치일 뿐, `localStorage`/쿠키/서버 저장이 전혀 없음(grep 결과 0건). 재방문해도 어디까지 들었는지 알 길이 없음 — 다회차 교육 플랫폼의 핵심 기능인데 부재.

## 🟡 구조적 UX 이슈 (전문가 관점)

6. **"워크시트" 탭에 "인쇄용" 배지가 붙어있지만 실제 인쇄 기능이 없음**
   배지: `app/courses/[courseSlug]/[sessionId]/page.tsx:31`. `window.print()` 호출, `@media print` CSS 모두 없음(grep 결과 0건). Ctrl+P 하면 사이드바·네비까지 통째로 인쇄됨 — 라벨과 실제 기능 불일치.

7. **강의/회차/스킬별 메타데이터가 전혀 없음**
   `generateMetadata`가 프로젝트 어디에도 없음. 동적 라우트(`app/courses/[courseSlug]/page.tsx`, `.../[sessionId]/page.tsx`, `app/library/skills/[skillSlug]/page.tsx`)는 전부 `app/layout.tsx:27-30`의 사이트 전역 title/description을 그대로 상속. 카카오톡·슬랙에 "3회차: GitHub 배포" 링크를 공유해도 미리보기엔 "ELEVO 교육 플랫폼"만 뜸. `openGraph`/`twitter`/파비콘 필드도 전무 (`public/`에 아이콘 파일 없음).

8. **검색/필터 기능 전무**
   강의 목록(`app/page.tsx`)과 스킬 목록(`app/library/skills/page.tsx:87-170`) 모두 정적 스크롤 리스트. `<input>` 요소가 프로젝트 전체에 하나도 없음. 스킬은 이미 `tags`/`author` 필드(`content/skills.config.ts`)가 있는데 필터링에 활용되지 않음 — 스킬이 20~30개로 늘면 바로 체감될 문제.

9. **본문 읽기 폭 제한이 없음**
   `.prose-light`(`app/globals.css:83-401`)와 `MarkdownViewer` 어디에도 `max-width` 제약이 없음. 세션 상세(`app/courses/[courseSlug]/[sessionId]/page.tsx:192-198`)의 넓은 데스크탑 화면에서 본문 한 줄이 1000px 넘게 늘어남 — 일반적 권장 줄 길이(60~80자)를 크게 초과해 가독성 저하.

10. **탭 UI에 ARIA 시맨틱 없음**
    `components/course/ContentTabs.tsx:36-46`의 "강의 내용"/"워크시트" 버튼에 `role="tab"`/`aria-selected`가 없음. `aria-*` 속성은 프로젝트 전체에 `SideNav.tsx`의 토글 버튼 2곳(`aria-label="메뉴"`, 접기/펼치기)뿐. 스크린리더 사용자는 탭인지 구분하기 어려움.

11. **태블릿 구간 대응 부재**
    `components/layout/SideNav.tsx`가 `lg:`(1024px) 브레이크포인트 하나로 사이드바를 온/오프(27, 54, 233, 258행). 768~1023px(아이패드 세로 등)에서는 폰과 동일하게 전체화면 오버레이 드로어로 덮임 — 중간 크기 화면 최적화가 없음.

12. **프레젠테이션 모드가 모바일 대응 전무**
    `components/presentation/PresentationMode.tsx`가 고정 위치 전체화면 `<iframe>`으로 데스크탑용 슬라이드를 그대로 띄움. `sm:`/`md:` 클래스가 파일에 전혀 없고, 슬라이드 자체도 스케일/줌 처리가 없음. 폰에서 열면 글씨가 매우 작거나 가로 스크롤이 필요할 것으로 보임.

## 🟢 있으면 좋은 것 (성장 대비)

13. **홈 "Active Courses" 그리드가 2열 고정**
    `app/page.tsx:72` — `grid-cols-1 md:grid-cols-2 lg:grid-cols-2`. 활성 강의가 5개라 마지막 줄에 1개만 남아 빈 공간이 어색함. 3열 이상도 고려.

14. **이전/다음 회차 네비게이션에 명확한 종료 신호 부재**
    `app/courses/[courseSlug]/[sessionId]/page.tsx:206-244` — 마지막/첫 회차일 때 "마지막 회차입니다" 같은 안내 없이 그냥 빈 칸(`<div style={{flex:1}}/>`)만 남음.

15. **`sitemap.xml`/`robots.txt` 없음**
    `app/sitemap.ts`, `app/robots.ts`, `public/robots.txt` 모두 부재 — SEO 발견성 관점에서 아쉬움.

16. **`StickyTOC` 표시 조건의 부모/자식 로직 불일치**
    부모(`app/courses/[courseSlug]/[sessionId]/page.tsx:200`)는 `tocHeadings.length >= 2`(h2+h3 합산)로 렌더 여부를 판단하지만, `components/viewer/StickyTOC.tsx:11,40`은 내부적으로 h2만 세서 `h2s.length < 2`면 다시 `null`을 반환. h2 1개 + h3 여러 개 같은 조합에서 컴포넌트가 마운트됐다가 조용히 빈 화면을 렌더 — 사용자에게 보이는 버그는 아니지만 로직이 꼬여 있어 정리할 가치는 있음.

## 우선순위 제안

가장 먼저 체감되는 문제는 **1번(죽은 CTA), 5번(진행상황 미저장), 4번(404 페이지)**이고, **3번(포커스 스타일)·7번(메타데이터)**은 접근성/공유 측면에서 비교적 저렴하게 고칠 수 있는 항목이다.
